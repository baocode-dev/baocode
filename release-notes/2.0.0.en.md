2.0 is a major release. Windows gets BaoCode Bash, and agents no longer fight PowerShell. One conversation can direct the others, a project can take in other folders, and your settings move to another computer in one file. The phone can send files to an agent, and an iPhone gets push notifications.

Windows: BaoCode Bash
- Agents no longer fight PowerShell. In most tasks, tool calls on BaoCode Bash respond 90% faster than on CMD or PowerShell, and the same work takes about a quarter of the steps.
- BaoCode Bash is a bash made for Windows, with more than 80 commands built in (rg, grep, sed, awk, find, jq, tar, diff and more) and no Git needed. Chinese output from cmd, PowerShell and Python comes out intact on a Chinese Windows.
- Settings → General → Command Line is now a list: BaoCode Bash (recommended, downloaded the first time you pick it), Git Bash, cmd, PowerShell or a program of your own. Both the built-in core and Claude Code use what you pick. With nothing picked, it works as before.
- If your commands run in neither bash, a note above the composer recommends it: install it in one click, or turn the note off for good.
- Agents are told to write paths as `C:/x`; `C:\x` and `/c/x` work too, `/tmp` is the system's temporary folder, and `cygpath` converts between them.
- With PowerShell picked, the built-in core writes PowerShell and reads its output as UTF-8.

New
- Conversations working together: with Settings → General → "Agents can coordinate other conversations" on, an agent can list and read your other conversations, send them messages and wait for them to finish, so one conversation can split work among the others.
- A project can take in other folders and stay as it is: its agents still start in its own folder and can read and write the added ones. Use "Add Folder…" in the sidebar's project menu or Edit Project; the side panel, terminals, @ mentions and the phone's file browser follow.
- Settings → Data Directory → "Move to Another Computer" exports your settings, upstreams and models, and keybindings to one file to import on another computer. API keys go only when ticked.
- In SSH remote terminals, `code <file>` opens a remote file or folder in BaoCode. Uploads and downloads show their progress and can be cancelled, and the remote explorer's context menu downloads files and folders.
- When an agent uses the Workflow tool, its subagents show as cards with their progress. A running subagent shows how long it has been at work.
- Customize has a Memory page to read, edit and delete what Claude Code remembers of a project. A project with no CLAUDE.md shows its AGENTS.md under Rules.
- Settings → Git Accounts adds GitCode, with gitcode.com's issues and pull requests.
- Find (⌘F / Ctrl+F) in the preview of a Markdown file or a plan.
- A link to a folder in a conversation shows it in the side panel's file tree; one outside the project opens in the file manager.
- Archived agents are grouped by folder, and "Archive All" on a project also takes its folder off the sidebar.
- Up to 100 images in a message (20 before).
- An image step has a button to copy the prompt it was made from.
- Settings → About shows this computer's device ID to copy, for a self-hosted relay that only lets listed devices in.

Phone (with phone app 0.2.0)
- Send files from the phone to an agent, including files shared from other apps.
- An iPhone in the background gets push notifications when an agent needs you or is done, and when a bot writes.
- Opening a conversation again brings only what changed, so it opens faster over a relay.
- Agents open sooner after the phone connects: your profile and picture are sent only when they change.

Improved
- Signed in with your own Claude account, BaoCode starts Claude Code under its own name rather than as an SDK caller when usage is counted.
- On a computer without ripgrep (most Windows ones), the built-in core uses the one in Claude Code's build, so it searches faster and finds more; under cmd it tells the model how to search there.
- A provider's model uses the context its upstream gives (such as 400K) rather than the 200K picked once for another model.
- A conversation continued in a terminal is read again by itself when you come back to BaoCode, without the refresh button.
- Listing sessions takes far less memory: an 800 MB session took 2 GB, now about 50 MB. Remote hosts no longer run out of memory and get killed over it again and again.
- A remote terminal printing a lot no longer slows the whole SSH connection; files and the agent keep responding.
- The context meter follows each request's final usage, so it is right mid-turn as well.
- Every 15 seconds only the open conversations are checked for changes, not every saved session.

Fixed
- Windows: typing a space after Chinese no longer makes the line jump.
- Windows: dragging a window by its header brings it to the front.
- Windows: when the window is narrow, the header matches the color around it.
- Windows: .NET programs such as MSBuild no longer crash when both HTTP_PROXY and http_proxy (and the like) are set.
- macOS: windows come back where they were after an external display sleeps.
- macOS: with accessibility on, the stash panel and other windows no longer crash the app.
- A provider's model in Plan with full access no longer has every command and subagent refused.
- Images sent through an OpenAI Responses upstream (such as vLLM) no longer fail with a 400.
- After a cut-off stream, the context meter no longer stays where the last turn left it.
- Blank lines some models (DeepSeek through a proxy) send before a tool call no longer show as an empty row.
- A drag on a conversation's text that sometimes selected nothing is redone as you drag. Selecting command output at a zoomed UI scale lines up again.
- Dictation in WeType no longer repeats the text.
- Formulas in a Markdown table's cells show typeset without clicking in.
- The sidebar no longer lists every bot's folder for a moment at start.
- Clearing a bot's chat or memory really makes it forget.
- Skills installed through a link (a Windows junction or symlink) load again, and a broken link says why.
