This release adds Antigravity account support, letting you sign in with a Google account for chat, web search and image generation, along with forking from any finished turn, a Built-in Core settings page, and much faster file search.

New
- Antigravity account provider: sign in with Google OAuth to view per-model quotas, rotate automatically across accounts when a pool runs out, and use native web search and image generation.
- Fork from any finished turn: click the fork button in a turn's footer to open a new conversation branched from that point.
- Built-in Core settings page: customize the system prompt by keeping the default, appending your own instructions, or replacing the default instructions.
- Web search and web fetch steps show the source sites' favicons, and MCP steps now have their own icon.
- Conversation minimap position: place the minimap on the left or right in Settings → Appearance → Minimap Position, aligned below the side panel's rail.
- Forked skill runs (such as /code-review) appear as a subagent card with live progress instead of looking idle.

Improved
- Switching to a model on another upstream mid-conversation takes effect directly without a confirmation dialog.
- Turn footer costs are computed live from Usage Prices and the usage ledger, updating as soon as prices change; unpriced calls no longer show a misleading $0.00.
- Pressing Esc alone no longer stops a running turn (use Ctrl+Esc, Cmd+Esc, Alt+Backspace, or the stop button instead).
- File search runs in parallel across worker threads, dramatically speeding up large projects and matching VS Code's results.
- Reduced sidebar sorting overhead and turned off accessibility semantics on macOS for smoother performance.

Phone (phone app 0.2.4)
- Switching models across upstreams no longer pops up a confirmation dialog.
- Antigravity providers show Google's logo, and quota pool names are spaced cleanly in Chinese.

Fixed
- Conversation text selection and copying: drag selection stays anchored while scrolling and ignores inner scrollbars, and copied text matches what is shown on screen.
- Fixed IME composition and Enter submission in the model picker search field. Thanks to @DedSecer.
- Fixed queued message drag alignment when the window is zoomed. Thanks to @clddup.
- Fixed Rollback in a remote workspace accidentally touching the local Trash. Thanks to @Sxuan-Coder.
- Windows: fixed apps launched by the installer failing to follow directory junctions, Fast IDE opening in a background window, and window resize border detection.
- Fixed API keys failing to save when PowerShell is restricted or no system keychain is available, and specified the default keychain in macOS security commands.
- Fixed remote hosts staying stuck on "Connecting" after being unreachable, Full Access still asking for confirmation in Plan mode, and started plans prompting again.
