This release fills in the details: themes can follow the system, models can be imported from ChatGPT credentials, the sidebar's projects can be ordered, the browser tools act more like a person, and a batch of Windows and input problems are fixed.

New
- Themes gain Auto: the app follows the system's light and dark, changing smoothly.
- ChatGPT credentials can be imported from JSON, and a model account's quota can be refreshed on its own.
- Sidebar projects can be ordered by recent activity, or dragged into your own order.
- browser_act can drag, use pen pressure, hold modifiers and hover; color, date and slider inputs take values too.
- The browser extension can reach local files, and says why when it may not.
- A subagent's message shows as its own card, not as the user's bubble.
- A stopped turn's work folds too, and a turn read across two pages folds as it did live.
- Past 560 wide, the side panel shows a commit's details beside the log, or as picked.
- Text shown in the side panel wraps as the editors do, toggled in its bar.
- The status bar shows how many lines a selection takes, beside its characters.
- An image's changes in Git show the image itself rather than empty text.
- Agents on SSH hosts act on this computer by default.
- A plan put to you is told of with a sound, and waits on you once the turn is over.

Improved
- The IDE workbench is rebuilt around services, registries and contributions, for what comes next.
- A login shell no longer starts from a cached environment.
- Reading a piece's lines no longer copies the whole piece.

Fixed
- Windows no longer crashes at shutdown; the tray's Quit chosen again quits, and the way out no longer crashes.
- On macOS, pasting in a text field no longer waits on the app that copied.
- With NumLock on, the numpad's 1 and 7 type digits.
- The Markdown preview's scrollbar shows an arrow, not the I-beam.
- Send now works on a queued message while tasks run in the background.
- An upstream's models going by one name are told apart, and a subagent's model reads as its own upstream's.
- Opening the usage page shows the calls being read.
- Theme preferences survive a failed save.
- A table's text selects as the text around it does.
- Branches containing a commit are listed.
- Tool calls on Windows show short file names.
- A terminal keeps its shell's selection.
- Removed SSH hosts are not connected to at startup.
- An account's quota refreshing turns as all of them do.
- Question options light up at once on hover.
- A folded group's header spins while any of its agents is at work, and agents at work or waiting are not lost under Show more.
- With only one pane in a chat window, the Close Pane keys (⌘W) close the window instead of doing nothing.
- Notifications from closed windows no longer appear.
- An inline message editor stays in view when opened and as it grows.
