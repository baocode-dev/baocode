This release can put files back when you edit a message, shows and uses Claude subscription limit resets, runs on Kylin and UOS Linux, and fixes how context usage is counted along with a batch of chat problems.

New
- When you edit an earlier message and send it again, the files the agent changed from that message on can go back as they were; what you or another conversation changed since is kept. Settings → General → Edited Messages: Ask Each Time, Undo the Changes or Keep the Changes. For Claude Code and BaoCode Agent; changes made by commands (Bash) are not tracked.
- Settings → Models shows, on the Claude Code row, the limit resets your subscription has: how many, what each clears, how much is used and until when. One is used only after you confirm.
- The Linux .deb runs on glibc 2.31 systems such as Kylin V10 SP1 and UOS 20.
- The phone app shows how full a conversation's context is (phone app 0.1.10).

Fixed
- Context usage shows what the model reported: a conversation full of screenshots no longer counts as millions of tokens, and tool results are counted by call, an image as one.
- Full access no longer asks about the safety checks Claude Code leaves to a person; your own ask rules still apply.
- File links an agent writes after changing folders open, and tell a file of your computer from one on the SSH host.
- When an upstream reports 0 input tokens, usage no longer shows every call as fully cached.
- The commit panel no longer stalls while the agent answers (hangs of seconds on Intel Macs).
- Dragging from the start of the text below a code block selects that text.
- The side panel's buttons no longer cover the chat find bar's close button.
