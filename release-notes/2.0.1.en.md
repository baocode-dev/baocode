This release completes conversations working together: a coordinating agent can start conversations on the model it picks, and those it handed work report back by themselves. Suggested replies now come in the agent's own reply, with no extra request. SSH hosts get a folder window like Finder's. The phone shows the quota, and big pictures arrive.

New
- Conversations working together are on by default (Settings → General → "Agents can coordinate other conversations", which turns it off). An agent can start a conversation on a task (in a new worktree on its own branch if asked) and pick its model; each conversation it started or wrote to reports back once done, failed or waiting on you, without the agent waiting on it.
- Coordinating steps say what was done and to which conversation, and a click opens it; messages from another conversation show as cards, with Answer while it waits on you. The conversations at work show over the composer.
- Suggested replies come at the end of the agent's reply, rather than one extra request with the whole conversation for each. They sit on top of the composer: a click puts one in to edit, a double click sends it, and Tab in an empty composer takes the first. They come in one after another.
- Opening a folder or file on an SSH host shows a window like Finder's or Explorer's: home, the drives and recent places at the left, back and forward, a path bar you can type in, a filter, New Folder, and hidden files when asked. Windows hosts reach drives other than C:.
- Save As in a remote project, and a new file's first save, pick the place on the host instead of saving to this computer.
- Settings → Browser shows each connected browser's own name, engine version and program path, and "Use This Browser" picks the one agents use. While the picked one is not connected, the last connected is used.
- When Claude Code's safeguards switch a conversation to a fallback model, the model button shows the model actually answering and why, and switches back in one click.

Phone (with phone app 0.2.1)
- The model picker shows the quota of the current model: each ChatGPT subscription account's, or the Claude plan's limits, with "Refresh Quota Data".
- Suggested replies sit over the composer: a tap puts one in, a double tap sends it.
- Coordinating steps and report cards show as on the computer.

Improved
- When every ChatGPT subscription account shows as out of quota, the quota is checked again before a request is refused. An account whose quota came back early used to stay out until its window ended, and the phone could not use it at all.
- Long conversations open much faster: steps folded away no longer take rows in the list. In a conversation of 5,600 items, a frame after opening went from 1–3 seconds to a few milliseconds.
- Upstreams are reached with the certificates your computer trusts (a company's CA, a proxy's), not Mozilla's roots alone, so they no longer fail with "TLS failed: Handshake error". A failed handshake says why.
- With full access, local_run no longer asks before every command.
- The Java language server uses the JDK in JAVA_HOME first, and no longer says Java is missing because it is not on PATH.

Fixed
- Big pictures on the phone no longer fail with "stream reset by peer".
- The phone shows pictures an agent made in a multi-folder workspace.
- Windows: as a bot's memory and group chats grow, Claude Code no longer fails to start on and off (its command line was too long). A bot on an upstream with a key no longer loses your MCP servers.
- Windows: with a dead powershell.exe alias on the PATH, reading API keys and the local tools of SSH projects no longer fail.
- Windows: dragging a Markdown table's horizontal scrollbar no longer selects text, and the pointer over it stays an arrow.
