自动更新没装上？
- 如果点了“立即重启更新”后应用关闭，再打开还是旧版本（1.0.0 和最早发布的 1.0.1 可能会这样），请从 https://baocode.dev/download 下载 1.0.2 直接安装，会覆盖原来的版本，设置和对话记录都会保留。

新功能
- 设置 → 外观：可以设置代码字体、字号、连字和界面文字大小，边调边预览；终端也使用这里的字体和字号
- 在输入框里粘贴很长的文本时，会收成一个标签（如“粘贴的文本 #1 +120 行”），不会再让窗口卡住；鼠标悬停可以预览，发送时完整内容随消息一起发出

1.0.1 的新功能
- 对话旁边的侧边面板：浏览项目文件，查看、暂存和提交 Git 改动（提交信息可以让 Claude 起草），打开终端和智能体在后台运行的命令
- 在侧边面板里查看 Claude 改过的文件，可以直接编辑、保存
- 工作区：把几个文件夹放在一起，智能体同时在这些文件夹里工作；文件夹里嵌套的 Git 仓库也能识别
- 在输入框里用 @ 引用别的对话；侧边栏里智能体的菜单可以复制会话 ID
- SSH 远程项目支持 macOS 主机
- 对话和 Markdown 文件里的 Mermaid 图表直接画成图，不用联网，可以放大查看
- 显示智能体的计划卡片；对话栏的宽度可以在设置里调整
- 资源管理器里可以复制、剪切、粘贴文件
- 侧边面板里，后台命令的输出用真正的终端显示：终端的字体、颜色、选择、查找和链接

1.0.1 的改进
- 第一次使用时自动跳过 Claude Code 的初始引导；找不到 Claude Code 时会直接说明
- 再次打开文件时代码高亮立即显示，不用等它重新着色
- 窗口较窄时，侧边栏和侧边面板只留最后打开的那个
- Windows：新安装默认只为当前用户安装，安装和自动更新都不再需要管理员权限；需要时仍可选择为所有用户安装
- 自动更新更可靠：Windows 上需要管理员权限时，确认窗口出现在最前面；更新没装上时，下次启动会提示，并给出下载页和安装日志
- 跳过的版本在侧边栏仍会显示“更新”按钮，只是不再弹出提醒
- 出错信息、Windows 的窗口日志和卡死报告都记录在数据目录的 logs 文件夹里，方便排查问题
- 交互面板里显示返回的快捷键

1.0.1 的修复
- 在 Dark 2026、Dark Modern 等主题下，对话里命令的程序名、字符串和参数看不见
- 在浅色主题下，对话里的命令和输出颜色太浅，现在和终端一样保证对比度
- 项目图标选了青色或洋红色时，在部分主题下不显示颜色
- 移动数据目录时如果有文件被其他程序占用，会指出是哪些文件，而不是只报复制失败
- 建议的提示词里带反斜杠（如 Windows 路径）或换行时，输入框会变成灰色的错误块
- Windows：显示器休眠后，或窗口隐藏时改变了大小，窗口内容会卡住不再更新
- Windows：在第二块屏幕上最大化的窗口从最小化恢复后，没有铺满屏幕，也不响应输入
- 打开“自定义”页面时，侧边面板的侧栏仍然显示
- Windows：“关于”窗口里的版本号不对，图标也不是应用的图标
