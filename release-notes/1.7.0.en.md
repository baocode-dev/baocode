New Git View

This release is all about a new Git view. The old Changes panel is replaced by a JetBrains-style Git log and Commit panel. Your everyday Git work happens in BaoCode, with AI ready to help: committing, branches, rebases, conflicts, stashes and comparisons. Besides, Windows now has a native Arm64 build, projects in WSL open directly, and BaoCode uses much less CPU on macOS.

New Git view
- Git log: the commit graph and branch and tag labels look as they do in JetBrains IDEs. Filter by branch, path, user or date, select several commits, and see the history of a file, a folder or a few lines. A branch tree beside the log has the branch actions.
- Commit panel: tick the files to commit, with no staging first. A tick box by each change lets you commit only some lines of a file. Each turn of an agent goes into a changelist of its own, and you can make your own changelists.
- Commit options: Amend, the author, Sign-off and whether to run Git hooks. Ctrl+M brings back earlier commit messages. While you write a message, its subject length and blank line are checked. Unversioned files can be added to .gitignore, and ignored files can be shown. A commit message can be written from the ticked changes alone.
- AI review before committing: turn it on, and AI looks over the ticked changes before they are committed. If something is wrong, the commit waits for you.
- Ask AI: about a commit in the log, or about changes and conflicts in the Commit panel. The request is put in the chat's input for you to look over before sending it. A button by a change in a diff puts that change, with its file and line, in the input.
- Branches: the branch popup in the status bar creates, checks out, merges, rebases and compares branches. Push has its own dialog. Update Project lets you choose merge or rebase.
- Rebases and conflicts:
  - Interactive rebase, Clean Up with AI to tidy commits, and Fixup.
  - A merge, rebase, cherry-pick or revert under way shows on top of the panel, with Continue, Skip and Abort.
  - A conflict can take one side in a click, open in a three-way merge dialog, or be merged by AI.
- Stash: stash and restore changes, in a Stash tab as in JetBrains IDEs.
- Remotes and repositories: manage remotes, and push tags to a remote or delete them there. Clone a repository from the start page.
- Worktrees: the IDE's Source Control can show another worktree. The branch menu under the chat's input creates and switches worktrees, and the log shows which worktree the AI is working in.
- Comparing:
  - Compare a file with a branch, a revision, the clipboard or another file.
  - Compare two folders, or compare a branch with the current one by its commits.
  - Diffs can collapse unchanged parts and ignore all whitespace.
  - An arrow in an editor's diff tab reverts that change. The agent's changes are marked in diffs.
- Editor:
  - JetBrains-style change markers by the line numbers, and Annotate with Git Blame.
  - New local history: each saved file keeps its versions for a week. Show Local History compares one with the file, and arrows take changes back.

Windows on Arm and WSL
- A native Arm64 build for Windows (BaoCode-1.7.0-setup-arm64.exe) runs natively on Snapdragon and other Arm PCs. Its updates come as Arm64 too. The download page has an Arm64 button.
- Open projects in WSL distributions. Open Remote Project lists this machine's distributions. Files, Git, terminals, language servers, Claude Code and reconnecting all run inside WSL, and the status bar says "WSL: <distribution>".
- Inside WSL, the Claude Code installed on Windows is no longer used by mistake. It failed with "Settings file not found: E:\dev\shm\…"; now BaoCode offers to install one in WSL.

Performance
- Much less CPU on macOS.
  - Windows where nothing changed, and the hidden Stash panel, are no longer drawn at every frame. While an agent runs, drawing a frame takes 1–2.5 ms instead of 6–11 ms.
  - Loading animations step together at 30 frames a second rather than each on its own. The IDE and the sidebar rebuild only when what they show changes.
- Git and checkpoints run in the background and no longer hold up the interface. A check when nothing changed runs 3 Git commands instead of 13.
- Changes in ignored folders such as build and node_modules no longer refresh the Git status. The model lists are worked out once.

Other new features
- Settings → Appearance has a Native Window Blur switch for the system blur under the windows on macOS and Windows 11. It is off by default.
- Word wrap in the editors: turn it on in Settings → Appearance, or toggle it with Alt+Z in an editor.
- Full screen, from the View menu or F11 (⌃⌘F on macOS).
- Sidebar:
  - Pin projects to the top. Collapse or expand all projects at once.
  - Edit a project's name and location; its conversations move along.
  - Hovering over a conversation shows the model it uses.
- Find in the editor and Search both match across lines, and multi-line text pasted keeps its line breaks. Search keeps its files to include and exclude, and its options, across restarts.
- Set up a language server of your own from Open Language Server Settings. It takes effect when saved, with no restart.
- Background tasks that ended can be cleared, one at a time or all at once.
- When the built-in core's agent ends its work with to-do items still open, the model is reminded to update its list.

Fixed
- The conversation minimap appears only once a conversation is long. Early on, it no longer comes and goes as you expand and collapse steps.
- Switching files in the Git log, or changes in the side panel, no longer flashes.
- After a rebase finishes, the Commit panel no longer keeps showing "Rebasing". Continue no longer fails with "Cannot continue the rebase".
- A WSL or SSH project removed from the list no longer comes back when you open another project on the same host.
- Files a subagent changes show in the review as they change. Its changes outside the project can be seen and undone. In a project opened through a link, files are no longer taken for files outside the project.
- With another upstream, availableModels in Claude Code's settings no longer swaps your model for a Claude one.
- A plan sent to you rather than written to a file now shows as a plan card, ready to start.
- A code block ends at its closing fence; the rest of the reply is no longer shown as code.
- Linux plays notification sounds and shows desktop notifications.
- On Chinese Windows, the output of a failed MCP command is no longer garbled. MCP servers that refused BaoCode's connection check with HTTP 415 now accept it.
- Typing with an input method over selected text replaces the selection.
- On Windows, the title bar over Settings shows only the window's buttons.
- On macOS, the app launched from the Dock or Finder can hold more than 256 open files. With many agents, terminals and language servers open, Claude Code failed to start with "Too many open files".
- A remote folder that failed to load on the first connection loads again once a retry connects.
