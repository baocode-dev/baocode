This release adds the Antigravity ACP upstream, so one conversation can move between its models and other upstreams', opens files picked in the search palette or a terminal in the chat's side panel, and fixes PDFs failing on OpenAI upstreams.

New
- Antigravity ACP upstream: BaoCode installs and updates Google's official Antigravity CLI and drives it over ACP. Sign in with a Google account to use its Gemini, Claude and GPT models, and switch between them and other upstreams' models in the same conversation.
- The context panel of an Antigravity conversation estimates what fills the context (system prompt, rules, skills, messages) and shows the account's weekly limits and when they reset.
- Antigravity's commands, edits, reads and web searches show as Claude Code's do; in full access its commands no longer ask one by one; its turns appear in the usage records.

Improved
- In the chat layout, a file picked in the search palette (Ctrl+P) or clicked in a terminal opens in the agent's side panel instead of switching to the IDE.
- Claude Code's own models always offer 200K / 400K / 1M context.
- The built-in core reads images and PDFs as Claude Code does: large images are resized, long PDFs are read by pages, and re-reading an unchanged file is pointed out.

Fixed
- A PDF read by the built-in core is no longer sent to OpenAI upstreams as text and failing; an upstream's failure is shown instead of retried silently.
- Antigravity: a failed command with no output no longer causes a 400 error; finished turns show the output speed; a 1M context shows as 1M.
