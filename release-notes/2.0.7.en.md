This release lets you copy, quote or ask by the way about text selected in the conversation, frees the chat grid from its 2×2, runs a stopped or failed last turn again in one click, and fixes several issues on Linux and Windows.

New
- Text selected in the conversation gets a bar over it: Copy, Quote (into the message being written, as a tag) and By the Way.
- The chat grid is no longer a fixed 2×2: split panes along rows or columns, as many as the window has room for.
- A stopped or failed last turn has a Run this turn again button; the model can be changed first, and as with an edit you're asked whether the files it changed go back.
- The agent suggests two to four replies; hold ⌘ or Ctrl while clicking to pick several and send them together.
- Images sent are kept as files and the agent is told where, so it can upload or attach the very one you sent.
- The conversation's files page has Open in Terminal.
- A model that failed its test: click Failed to copy the error, or use Copy Error in the row's menu.

Improved
- A skill run from a slash command (such as /code-review) shows its work as it goes instead of staying empty until done.
- Messages queued behind a running turn go back into the composer when the app quits, kept for the next run.
- A conversation with scheduled jobs or a loop waiting keeps its process when you switch away, so they come on time.

Fixed
- The selection bar showing on only every other selection.
- A message's editor opening off its message when Interface Size isn't 100%, or going out of view in a short window.
- Windows: closing the window with no tray icon up minimizes it instead of leaving the app running out of reach; PowerShell Store execution aliases are recognized.
- Windows: Ctrl+Y redoes in the markdown editor and the composer.
- Linux: the package declares its GL libraries, fixing a crash at start on minimal desktops; a certificate bundle with stray bytes no longer drops every certificate; code fonts stay monospaced under CJK locales.
- Suggested replies with inline code in them no longer all show as plain text.
