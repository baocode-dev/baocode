这一版把对话协作补完整：统筹的 agent 可以自己开新对话、指定模型，干完活的对话会自己回报。推荐回复改由 agent 在回复里直接给出，不再额外发请求。连接 SSH 主机时有了像 Finder 一样的文件夹窗口。手机能看额度、看图更稳。

新功能
- 对话协作默认打开（设置 → 通用 →「Agent 可以统筹其他对话」，可以关掉）。agent 可以开新对话分派任务（可以放进新的 worktree 和分支），指定用哪个模型；它开过或发过消息的对话做完、出错或等你处理时会自己回报，不用一直等着。
- 协作的步骤会写明对哪个对话做了什么，点一下就能打开那个对话；别的对话发来的消息显示成卡片，等你处理时有「回答」按钮。输入框上方列出正在干活的对话。
- 推荐回复由 agent 在回复末尾直接给出，不再为每条建议额外发一次带整段对话的请求。推荐回复显示在输入框最上方，单击放进输入框编辑，双击直接发送，空输入框里按 Tab 取第一条；一条一条依次出现。
- 打开 SSH 主机上的文件夹或文件时，弹出像 Finder / 资源管理器那样的窗口：左边是主目录、各个磁盘和最近位置，有前进后退、可编辑的路径栏、筛选、新建文件夹，隐藏文件按需显示。Windows 主机也能进 C: 以外的盘。
- 远程项目的「另存为」和新文件第一次保存，会在远程主机上选位置，不再存到本机。
- 设置 → 浏览器显示每个已连接浏览器的真实名字、内核版本和程序路径，可以「使用这个浏览器」指定 agent 用哪个。指定的浏览器没连上时用最后连上的那个。
- Claude Code 因安全策略把对话临时换成备用模型时，模型按钮会显示实际在用的模型并提示原因，可以一键切回。

手机（需要手机版 0.2.1）
- 选模型的面板里能看到当前模型的额度：ChatGPT 订阅的每个账号，或 Claude 官方订阅的用量限制，可以「刷新额度数据」。
- 推荐回复显示在输入框上方，单击放进输入框，双击直接发送。
- 对话协作的步骤和回报卡片和电脑上一样显示。

改进
- ChatGPT 订阅的所有账号都显示额度用完时，会先重新查一次额度再拒绝请求。以前额度提前恢复了也要等到窗口结束才能用，手机上会一直用不了。
- 很长的对话打开更快：折叠起来的步骤不再占列表行。一个 5600 多项的对话，打开后每帧从 1–3 秒降到几毫秒。
- 上游使用电脑系统里信任的证书（公司 CA、代理的证书等），不再因为只认 Mozilla 根证书而报「TLS failed: Handshake error」。握手失败时会说明原因。
- 完全访问权限下，local_run 不再每条命令都询问。
- Java 语言服务优先使用 JAVA_HOME 里的 JDK，不再因为 PATH 里没有 java 就说没装。

修复
- 手机看大图不再报「stream reset by peer」。
- 手机能显示多文件夹工作区里 agent 生成的图片。
- Windows：Bot 的记忆和群聊多了以后，Claude Code 不再时好时坏地报「无法启动」（命令行超长）。使用带 key 的上游时，Bot 不再丢失你的 MCP 服务器。
- Windows：PATH 里有失效的 powershell.exe 别名时，读取 API key、SSH 项目的本地工具等不再失败。
- Windows：拖动 Markdown 表格的横向滚动条不再选中文字，鼠标在滚动条上显示为箭头。
