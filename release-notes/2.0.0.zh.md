2.0 是一个大版本。Windows 上有了 BaoCode Bash，Agent 再也不会大战 PowerShell 了。一个对话可以指挥其他对话干活，项目能挂上别的文件夹，设置能整份搬到另一台电脑。手机可以给 agent 发文件，iPhone 能收到推送。

Windows：BaoCode Bash
- Agent 再也不会大战 PowerShell 了。大多数任务里，用 BaoCode Bash 比用 CMD 和 PowerShell 工具调用响应快 90%，完成同样的事步数只有约四分之一。
- BaoCode Bash 是专为 Windows 做的 bash，内置 rg、grep、sed、awk、find、jq、tar、diff 等 80 多个命令，不用装 Git。中文 Windows 上 cmd、PowerShell、Python 的中文输出也不会乱码。
- 设置 → 通用 → 命令行改成下拉框，可以选 BaoCode Bash（推荐，第一次选中时自动下载）、Git Bash、cmd、PowerShell 或自定义程序，内置内核和 Claude Code 都用这里选的。不选时和以前一样。
- 还没用上 bash 的用户会在输入框上方看到推荐，可以一键安装，也可以永久关掉。
- agent 会被告知路径统一写成 `C:/x`；`C:\x`、`/c/x` 也都认，`/tmp` 是系统临时文件夹，`cygpath` 可以互转。
- 选 PowerShell 时，内置内核会按 PowerShell 的写法跑命令，输出 UTF-8。

新功能
- 对话协作：打开设置 → 通用 →「Agent 可以统筹其他对话」后，agent 能列出、查看你的其他对话，给它们发消息、等它们做完，用一个对话指挥其他对话分工干活。
- 项目可以添加其他文件夹，项目本身不变：agent 还在原文件夹启动，同时能读写添加的文件夹。在侧边栏项目菜单的「添加文件夹…」或编辑项目里设置，侧边面板、终端、@ 提及和手机的文件浏览都会跟着变。
- 设置 → 数据目录 →「迁移到另一台电脑」：把设置、上游和模型、快捷键导出成一个文件，在另一台电脑上导入。API key 只有勾选时才导出。
- SSH 远程终端里可以用 `code 文件` 在 BaoCode 里打开远程文件或文件夹。上传、下载显示进度，可以取消；远程文件浏览器右键可以下载文件和文件夹。
- 用 Workflow 工具时，对话里会显示它的子 agent 卡片和每个子 agent 的进度。运行中的子 agent 显示已运行时长。
- 自定义里新增「记忆」页，可以查看、编辑、删除 Claude Code 对这个项目的记忆。没有 CLAUDE.md 的项目会在规则里显示 AGENTS.md。
- 设置 → Git 账号支持 GitCode，可以查看 gitcode.com 的 issue 和 PR。
- Markdown 文件和计划的预览里可以按 ⌘F / Ctrl+F 查找。
- 对话里指向文件夹的链接，点开后在侧边面板的文件树里定位，项目外的在文件管理器里打开。
- 已归档的 agent 按文件夹分组显示；对项目「全部归档」会把这个文件夹一起从侧边栏收起。
- 一条消息最多可以带 100 张图片（以前 20 张）。
- 生成图片的步骤旁边有复制按钮，可以复制生成时用的提示词。
- 设置 → 关于显示这台电脑的设备 ID，可以复制（自建只允许列出设备的中继时用）。

手机（需要手机版 0.2.0）
- 手机上的文件可以发给 agent，其他应用分享的文件也能直接发到对话里。
- iPhone 在后台时，agent 需要你处理、做完，或 Bot 发来消息，会收到推送通知。
- 重新打开对话时只传有变化的部分，经中继连接时打开更快。
- 手机连上电脑后打开 agent 更快：头像等个人资料只在变了时才发送。

改进
- 使用自己的 Claude 账号登录时，BaoCode 会以自己的名字启动 Claude Code，不再被当作 SDK 调用来统计用量。
- 内置内核在没有 ripgrep 的电脑上（大多数 Windows）会用 Claude Code 自带的那份，搜索更快更准；用 cmd 时也会告诉模型怎么搜索。
- 第三方模型使用上游给出的上下文长度（比如 400K），不再沿用以前给别的模型选的 200K。
- 会话在终端里继续聊过后，回到 BaoCode 会自动重新读取，不用再点刷新。
- 列出会话时内存占用大幅降低：800 MB 的会话以前要 2 GB，现在约 50 MB。远程主机上不会再因为内存不足反复被杀。
- 远程终端大量输出时不再拖慢整个 SSH 连接，文件和 agent 照常响应。
- 上下文用量和最终请求的用量对齐，回合中途也更准。
- 每 15 秒只检查打开的对话有没有变化，不再检查所有保存的会话。

修复
- Windows：在中文后面输入空格时，整行不再跳动。
- Windows：拖动标题栏会把窗口提到最前面。
- Windows：窗口较窄时，标题栏颜色和周围一致。
- Windows：同时设置了 HTTP_PROXY 和 http_proxy 这类只差大小写的变量时，MSBuild 等 .NET 程序不再崩溃。
- macOS：外接显示器睡眠后，窗口回到原来的位置和大小。
- macOS：开着辅助功能时，暂存面板等其他窗口不再导致闪退。
- 第三方模型在计划模式、完全访问权限下，命令和子 agent 不再全部被拒绝。
- 通过 OpenAI Responses 上游（如 vLLM）发送图片不再报 400。
- 流式输出中断后，上下文用量不再一直停在上一轮。
- 某些模型（经代理的 DeepSeek）在调用工具前输出的空行不再显示成空白行。
- 在对话文字上拖动有时选不中，现在拖动过程中会重新选取。缩放界面后选中命令输出不再错位。
- 微信输入法语音输入时，文字不再重复出现。
- Markdown 表格单元格里的公式不点进去也能正常显示。
- 启动时侧边栏不再短暂列出所有 Bot 的文件夹。
- 清空 Bot 的对话或记忆后，它真的会忘掉。
- 通过链接（Windows 目录联接、符号链接）安装的技能能正常加载，链接失效时会说明原因。
