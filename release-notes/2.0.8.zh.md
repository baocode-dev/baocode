这一版给第一次打开的用户准备了一段演示对话，上游和模型可以拖动排序，删除改为可以撤销，和手机之间传文件不再限制大小。

新功能
- 第一次打开、还没有项目时，自动建好 ~/BaoCode 项目，并播放一段演示对话：网页搜索、子代理、改代码、跑测试、生成图片都在里面，但什么都不会真的执行。Ctrl+P 里的「查看演示对话」可以再看一遍。
- 设置 → 模型里，上游和上游里的模型都可以拖动排序，模型选择器和各处的下拉都跟着这个顺序。
- 删除对话、从列表移除项目、删除工作区不再弹确认框：立即隐藏，左下角 5 秒内可以撤销。
- 和手机之间传文件改成分块传输，不再有 8 MB 的上限。
- 自带内核支持 CLAUDE_AUTOCOMPACT_PCT_OVERRIDE，可以让自动压缩提前触发。

改进
- 文件改动默认折叠成一行，点开查看 diff；设置 → 外观里可以改回卡片。
- 对话栏默认宽度改为 1040，最窄仍可调到 720。
- 后台任务超过三个时不再默认折叠。
- 没有配置模型时不再自动弹出模型欢迎窗口，改由对话下方的提示条和按钮打开。
- 关掉生图模型后，历史对话里生成的图片照常显示。
- 多文件夹工作区里，提交面板只列出 Git 日志里选中的那个仓库。

修复
- Antigravity：会话信息更新时不再覆盖已有的标题。
