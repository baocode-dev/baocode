This release rebuilds the agents' window with cards, and the sidebar, conversations and side panel can be arranged in four layouts. A Windows computer can now be an SSH host. /fork is new, and an agent's questions stay in the conversation with your answers.

New
- The agents' window is laid out in cards: the sidebar, the conversations and the side panel each on their own. The side panel's Layout button switches between four arrangements, and the sidebar can sit at the right.
- A conversation's title and buttons are on its own card. With split panes there is one set of buttons at the window's top right, and each pane's details are on its card instead of taking a row of their own.
- A row under the conversation shows where the agent works (a click copies the path) and how full its context is, with a warning past 80%.
- Windows as an SSH host: connecting, files, a PowerShell terminal and language server diagnostics all work. The status bar shows the host's system.
- In SSH projects, the remote agent can use the tools that act on this computer, with ports forwarded both ways.
- /fork: type /fork in the input to copy the conversation and go on in a new one.
- Once you answer an agent's questions, each question and your answer stay in the conversation, also when the turn is folded.
- Each conversation has its own Git log in the side panel; the local changes under it fold.
- File tabs in the editor and the side panel can be dragged into another order.

Phones
- Browsing files on the phone shows the files Git ignores, dimmed.
- File links in a bot's replies open on the phone.
- After the computer restarts, a new conversation on the phone no longer shows as an old one.

Improved
- Without Claude Code installed, BaoCode's built-in core is used by default, and the official CLI is no longer suggested.
- Edit cards show their changes inline.
- A code block being written lays out and colors only what changed, so long replies no longer stutter.
- History reads only the part of a session shown, and a session file that grows is read on from where it was read. Large requests' JSON is handled off the UI thread, using less CPU.
- File links in the chat resolve paths as the agent's tools do, so `~` and relative paths open.
- Bao Dark and Bao Light's grays are closer to neutral gray; the sand gold accent is unchanged.
- In a narrow conversation, a finished turn's time, speed, cost and tokens wrap onto another line.
- The side panel no longer has a browser page; the agent's browser tools work as before.

Fixed
- Sessions whose first message carried an added note (the file open in the editor, sent from the phone, Ask mode) no longer disappear from the list after a restart. Sessions starting with a command such as /goal are listed too.
- The input could stop taking text after the input method's connection dropped (macOS Pinyin).
- A code block being written could occasionally freeze the window (Intel Macs).
- Code blocks are colored again after switching themes.
- A terminal paused on Linux reads its output again once resumed.
- Stashing works with Git before 2.13.
- Home and End move to the line's start and end in the Markdown editor.
