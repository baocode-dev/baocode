Mostly fixes in this one: the mouse wheel no longer stops working on Windows, and workspace windows are titled by their name, not an ID. New models of a ChatGPT subscription show up without waiting for a BaoCode release.

New
- New models of a ChatGPT subscription no longer wait for a BaoCode update: the model list asks baocode.dev for the latest Codex version first, so a new model shows up without a restart. The per-upstream "Codex Version" setting is gone.

Phone (phone app 0.2.2)
- Push your iPhone with curl: turn on Settings → Notifications → Push from scripts, and your scripts, shortcuts and CI can notify the phone; a tap can open a link or run a shortcut. See baocode.dev/push.

Fixed
- Windows: the mouse wheel no longer stops scrolling altogether after a display change or waking from sleep, until the window was resized.
- A workspace's window title, the Window menu and Switch Window show the workspace's name instead of an ID, and follow it when renamed.
- Conversations an agent starts by itself in a temporary folder (/tmp and the like) no longer fill the sidebar; only those you opened or wrote to from the app are listed.
- With the automatic core and no upstream model, connecting to an SSH host no longer installs Claude Code on it; you're asked to pick a model instead.
- Suggested replies a model writes together are split into separate ones again, instead of one long pill.
- Diagnostics: a key that types nothing in a text field is now logged, to track down "a key suddenly stopped typing".
