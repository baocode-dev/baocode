这一版的重点是手机上的 Bot：像人一样和你聊天的智能体，跑在你的电脑上，在手机上和它们对话。另外，分屏可以各自带侧边栏、拖动换位置，还修了一些问题。

Bot（在手机上用，需要这一版桌面端）
- 每个 Bot 有自己的名字、头像、性别、签名、说话风格和模型。默认有一个助手，也可以自己新建。
- Bot 能做什么由你逐项打开：照看你的 agent（查看、停止、重试、归档、发消息、开新的）、使用你的浏览器、在 agent 等你或出错时主动告诉你。
- Bot 可以上网，会记住你说过的事；在 设置 → 模型 里打开图片模型后还能生成图片。你发给它的图片它也能用，比如拿来当头像。
- Bot 不读写电脑上的项目文件，项目里的活交给 agent。

新功能
- 分屏时每个对话有自己的侧边栏，单独显示或隐藏。
- 拖动分屏的标题栏，可以把它放到另一个旁边，或者两个互换位置。把项目的「新建 agent」拖到分屏上，会在旁边开一个新的。
- 侧边栏里的文件可以用默认应用打开，菜单里还有在终端、文件管理器里打开和复制路径。
- IDE 左侧活动栏底部加了设置按钮。
- 手机上能看到 agent 生成的图片、工具返回的图片、浏览器的每一步操作，以及目标和本轮用量。
- 内置核心和 Claude Code CLI 2.1.293 对齐。

修复
- 进程还在启动时点「立即发送」，会等它准备好再发。
- 读取上游 key 失败不会被记住，也不会冲掉期间新设的 key。
- 浏览器发来的长消息收全了才处理。
- 用量以字符串返回的模型，用量能正确显示。
- 从输入框复制时保留标签，粘贴到别的应用是纯文本。
- Markdown 文件的改动默认显示渲染效果，点一下看 diff；侧边栏的文件树带 Git 状态。
- Git 日志的图完整显示，详情可以复制，分支也显示出来。
- 提交面板的勾选框看得清，改动可以按列表或树显示，窗口窄时按钮不再挤出去。
- Windows：分屏标题栏的按钮作用于各自的 agent，和 macOS 一样；改用 Skia 绘制，画面更快、更省内存。
