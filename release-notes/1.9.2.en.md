This release fixes a batch of chat, model and SSH problems, brings SSH remote to Linux hosts on RISC-V, and lets models go through magpie's gateway.

New
- SSH remote works with Linux hosts on RISC-V.
- With magpie installed, Settings → Models offers Connect magpie: an upstream that follows magpie's local gateway, nothing filled in by hand.
- The changed files list in the activity strip can be dragged taller by its edge.

Fixed
- A log with ANSI colour codes opens as text, not as a binary file.
- New conversations on OpenCode's DeepSeek no longer fail with a 400.
- When an upstream's stream breaks off and Claude Code asks again, the reply no longer shows twice.
- After a restart, every tab open in a chat pane comes back, not only the one shown.
- Commands in .claude/commands are yours to run; the model runs one only where its file allows it.
- An unreadable file in .claude/rules is skipped instead of keeping all the project's rules from loading.
- An expanded command output card scrolls inside itself under the wheel, with a scrollbar you can drag.
- SSH folders open from recent projects and from the system's open requests.
