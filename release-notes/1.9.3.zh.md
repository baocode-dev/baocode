这一版加了编辑消息时恢复文件，能查看和使用 Claude 订阅的额度重置，Linux 版能在银河麒麟、统信 UOS 上运行，另外修正了上下文用量的统计和一批对话问题。

新功能
- 编辑之前的消息再发送时，如果 Agent 从那条消息起改过文件，可以选择把这些文件恢复原样，你或其他对话后来的改动会保留。设置 → 通用 → 修改历史消息里可以选每次询问、撤回改动或保留改动。支持 Claude Code 和 BaoCode Agent，命令（Bash）做的改动不在其中。
- 设置 → 模型里，Claude Code 一行会显示订阅可用的额度重置：有几次、各自清掉什么、用了多少、到什么时候，确认后才会使用。
- Linux 的 .deb 安装包能在 glibc 2.31 的系统上运行，比如银河麒麟 V10 SP1 和统信 UOS 20。
- 手机版能看到对话的上下文用量（需要手机版 0.1.10）。

修复
- 上下文用量按模型实际报告的显示：带大量截图的对话不再被算成几百万 token，工具结果按调用计算，一张图算一份。
- 完全访问模式下，不再询问 Claude Code 留给人确认的安全检查；你自己设的询问规则仍然有效。
- Agent 切换目录后写出的文件链接能正确打开，也能分清是本机的文件还是 SSH 主机上的文件。
- 部分上游把输入 token 报成 0 时，用量不再全部显示为命中缓存。
- Agent 回复时提交面板不再卡顿（Intel Mac 上曾出现几秒的卡死）。
- 在代码块下方的文字上从行首拖动，能正常选中这段文字。
- 侧边面板的按钮不再挡住对话查找栏的关闭按钮。
