这一版 Linux 改由应用自己绘制标题栏，Antigravity 可以向你提问、长时间运行的命令不再被误判为卡住，写在一行里的 `<details>` 也能折叠了。

新功能
- Linux：窗口顶部改为应用自己绘制的标题栏，和 Windows 一样；拖动空白处移动窗口，双击按系统设置最大化或最小化。
- Antigravity：它提出的问题会以问答卡片的形式交给你回答，子代理的提问也一样。
- Antigravity：它的步骤清单显示为任务列表；对话进行中发送的消息会立即交给它，不再等这一轮结束。

改进
- Antigravity：调用 BaoCode 自带的 MCP 工具（浏览器、会话等）时显示返回结果，不再是「(no output)」；通过 `call_mcp_tool` 调用的 MCP 工具按 MCP 工具显示和审批，不再当作 Bash 命令。
- 写在一行里的 `<details><summary>…</summary>` 也能折叠，整段写在一行、连 `</details>` 都在同一行的也可以；长回复分段时不会从这样的折叠块中间切开。

修复
- Antigravity：运行很久的命令或 MCP 调用不再被当作卡住而重启；它没有响应停止时，15 秒后直接结束进程，停止按钮仍然有效。
