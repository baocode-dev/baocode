这一版重做了智能体窗口：改成卡片式布局，侧边栏、对话和侧边面板可以选四种排布。Windows 电脑也能作为 SSH 远程主机了。另外新增 /fork，agent 提问后对话里会留下问答。

新功能
- 智能体窗口改成卡片式布局，侧边栏、对话和侧边面板各在一张卡片上。侧边面板的「布局」按钮可以在四种排布之间切换，侧边栏也能放在右边。
- 对话的标题和按钮放在对话自己的卡片上。分屏时窗口右上角只有一组按钮，每个窗格的信息显示在各自的卡片里，不再另占一行。
- 对话下方一行显示 agent 的工作目录（点一下复制路径）和上下文用量，超过 80% 时提示。
- Windows 可以作为 SSH 远程主机：连接、文件、PowerShell 终端、语言服务器诊断都能用。状态栏显示主机系统。
- SSH 项目里，远程 agent 也能用操作本机的工具，端口双向转发。
- /fork：在输入框里输入 /fork，复制当前对话，在新对话里接着聊。
- agent 提问、你回答之后，对话里会留下每个问题和你的回答，整轮折叠后也看得到。
- 侧边面板里每个对话有自己的 Git 日志，下面的本地改动可以折叠。
- 编辑器和侧边面板的文件标签可以拖动排序。

手机
- 手机上浏览文件时能看到被 Git 忽略的文件，显示为灰色。
- Bot 回复里的文件链接在手机上能打开。
- 电脑重启后，手机上的新会话不会再显示成以前的会话。

改进
- 没装 Claude Code 时，默认使用 BaoCode 内置内核，不再推荐安装官方命令行。
- 编辑卡片的改动改为行内显示。
- 流式输出代码块时只重排、重新着色变化的部分，长回复不再卡顿。
- 会话历史只读取要显示的部分；会话文件变长时接着上次的位置读。大请求的 JSON 不在界面线程上处理，CPU 占用更低。
- 聊天里的文件链接按 agent 工具的方式解析路径，`~` 和相对路径都能点开。
- Bao Dark / Bao Light 的灰色更接近中性灰，沙金主色不变。
- 对话较窄时，回合末尾的耗时、速度、费用、tokens 会自动换行。
- 侧边面板不再有浏览器页，agent 的浏览器工具照常可用。

修复
- 第一条消息前带有附加提示（编辑器里打开的文件、从手机发送、Ask 模式）的会话，重启后不再从列表里消失。以 /goal 等命令开头的会话也会列出来。
- 输入法连接断开后输入框打不进字的问题（macOS 自带拼音）。
- 流式输出代码块偶尔卡住窗口的问题（Intel Mac）。
- 换主题后，代码块会重新着色。
- Linux 上终端暂停后恢复，能继续读取输出。
- Git 2.13 以前的版本也能暂存（stash）。
- Markdown 编辑器里 Home / End 移到行首、行尾。
