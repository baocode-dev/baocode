Mostly about bots looking after your agents: they start conversations, hand out work, wait for it and check the files changed, just as an agent in a conversation does. Also, Quick Open finds every file of a large project, and big folders on a Linux remote host no longer stall the connection.

New
- Bots manage agents with the same tools as a conversation: a new conversation can be given a model or a worktree on a new branch; a message to a busy one is queued instead of refused; whole replies are read, a conversation waited for, and the files it changed checked.
- When a conversation is compacted early, the divider says why: the provider refused the request as too long, the model taking less than the context set. The divider is translated too.
- Java: the modules of a multi-module project share one language server; when a project fails to import you get a notice with its log, instead of only "No references found". Thanks to @bestK.

Fixed
- Conversations a bot handed work to are still known as its own after the desktop restarts, and it is still told when they are done.
- After the desktop restarts, the phone is no longer pushed the bot's earlier messages again.
- A bot without Agent notifications tells you, when it hands out work, that it won't hear when it is done.
- Quick Open (⌘P / Ctrl+P) finds every file of a very large project, not only the first 50,000.
- Linux remote hosts: with tens of thousands of folders watched, a batch rename or a reconnect no longer stalls the connection for tens of seconds.
- Diagnostics: on a Mac, the window suddenly not taking clicks while typing with an input method is now logged, to track it down.
