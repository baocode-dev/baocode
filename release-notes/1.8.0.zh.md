这一版重做了电脑和手机之间的连接，新增调用统计、/btw 旁问，Diff 和多窗格也大改了一轮。手机上需要 0.1.5，升级后要重新配对一次。

手机
- 电脑和手机改用新的连接方式：同一网络里直连，跨网络时自动打洞直连，都不行才经中继，内容端到端加密。电脑换了 IP 也能连上。
- 设置 → 手机 里可以自动选中继、指定一台，或填自己部署的中继；手机上不用设置。
- 设置 → 手机 最上面直接显示手机版的下载二维码，和官网下载页一样；点配对二维码可以复制链接。
- 安卓版以后在应用里自动下载更新，点一下就装好。

新功能
- 调用统计：记录每个上游、每次调用的用量和费用，设置里有看板，每个对话也有自己的用量页。
- /btw：在当前对话旁边另开一个对话问点别的，Esc 回到原来的对话。
- Diff 改成 JetBrains 式的左右对照和行内对照，右边有一条总览；每处改动旁边都能撤销。审阅按每个对话自己的改动来看。
- 多窗格：项目的 agent 打开在它自己的窗格里；一个窗格里叠着的内容显示成标签；每行、每列的大小可以单独拖。
- 终端可以拖动排序，聊天面板和侧边面板共用同一组终端。
- ⌘L / Ctrl+L 把编辑器里选中的代码加进聊天输入框；排队中的消息可以拖动调整顺序。
- 侧边栏直接打字就能搜项目；上游可以用自定义模型和接口地址。

改进
- agent 工作时界面最多每秒刷新 30 帧，更省电。
- 搜索在每一层都遵守 .gitignore，包括嵌套的仓库。

修复
- Windows 窗口周围不再出现一圈白边。
- 停止后台命令时不会再卡住。
- 每个标签页的编辑器回到上次的位置；语言服务器启动期间也能跳转定义和引用。
