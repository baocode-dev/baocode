这一版主要改进手机：电脑可以设成仅直连、不经中继；在手机上发消息时，agent 会改用适合手机看的纯文字回复；Bot 也更好用了。另外加了鼠标侧键前进后退、公式复制成 TeX、Gitee 支持，用量统计也能按上游的方式计价。手机上建议更新到 0.1.6，仅直连需要 0.1.6。

手机
- 设置 → 手机 → 中继 新增「仅直连」：不经任何中继，手机直接连电脑的地址，适合有公网 IP 或在路由器上做了端口转发的电脑。UDP 端口可以自己定（1024–65535，默认 47100），设置里会显示电脑的公网地址。
- 手机 0.1.6 的电脑详情页能看到电脑的中继设置、端口和地址，还能手动添加「域名或 IP:端口」（比如动态域名），并测试能不能连上。
- 在手机上发消息时，会悄悄告诉 agent 你正在用手机，它会用适合手机看的纯文字回复；回到电脑上再发消息，它会恢复平常的格式。这些提示你看不到，也不改系统提示词，不影响缓存。
- Bot 不再卡在没人能回答的提问上，改为直接用文字问你。
- Bot 可以用那些不需要有人守在电脑前的工具，你自己配置的 MCP 服务器也能用。
- Bot 收到 agent 的哪些消息可以按规则决定（Bot 文件夹里的 WATCH.md）：叫醒它、只让手机通知你，或者忽略；被叫醒却没什么要说时不再出声。
- 项目置顶在电脑和手机之间同步。
- 删掉的 Bot 留下的文件夹不再作为项目出现在侧边栏和手机的文件里。

新功能
- 鼠标侧键可以后退、前进：退出子 agent、在改动和 Git 日志之间来回、退出设置页，或者回到上一个选中的 agent。IDE 标题栏的搜索框旁边也有后退、前进按钮。
- 聊天里的公式可以整个选中，复制出来是 TeX 源码。
- baocode://file/ 链接可以打开文件并跳到指定行，和 vscode://file/ 一样。
- Vue 文件支持跳转定义。
- 支持 Gitee；自建 GitLab 可以用 http，也认你自己信任的证书。
- 用量统计按上游的方式计价：按提示长度分档、按时段（比如 DeepSeek 的错峰优惠）、按服务等级，以及按次收费和工具费。正在进行的调用也会显示在调用列表里。

改进
- 搜索结果会跟着文件的改动自动更新。
- 编辑卡片的文件头和代码块的标题更紧凑。
- Windows 上读取系统代理不再启动 reg.exe。

修复
- Claude Code 放弃的请求（超时、中断）现在也会取消上游的请求，并记为已取消。
- 模型很多时修改 settings.json 不再卡住窗口（Windows 上以前要好几秒）。
- 终端里很长的行不再让界面卡住。
- Windows 上用划词、复制工具选中文字时，窗口缩放不再被重置成 100%。
- 在窗口外松开鼠标后，聊天里滚动滚轮不再选中文字。
- SSH 主机的关闭按钮回到标题栏右端。
- Windows 上某些直接退出的崩溃现在也会留下崩溃报告。
