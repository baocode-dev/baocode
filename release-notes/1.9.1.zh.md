这一版主要补齐细节：主题可以跟随系统，模型能导入 ChatGPT 凭据，侧边栏项目可以排序，浏览器工具更接近真人操作，另外修了一批 Windows 和输入相关的问题。

新功能
- 主题新增「跟随系统」，系统切换深浅色时自动跟着变，切换过程有平滑过渡。
- 可以从 JSON 导入 ChatGPT 凭据；模型账号的额度可以单独刷新。
- 侧边栏的项目可以按最近活动排序，也可以手动拖动排序。
- 浏览器工具的 browser_act 支持拖拽、画笔压力、按住修饰键和悬停；颜色、日期、滑块输入框也能设值。
- 浏览器扩展可以访问本地文件，没有权限时会说明原因。
- 子代理的消息显示为它自己的卡片，不再像用户的气泡。
- 被停止的回合也能折叠；跨页读取的回合折叠效果和当时一致。
- 侧边面板宽于 560 时，Git 的提交详情可以显示在日志旁边，也可以按选择切换。
- 侧边面板里的纯文本可以像编辑器一样自动换行，在面板栏切换。
- 状态栏显示选区占多少行，和字符数放在一起。
- Git 的图片改动直接显示图片，不再是一片空白。
- SSH 主机上的 agent 默认可以操作本机。
- 计划提交给你时会有提示音；这一轮结束后会等你确认。

改进
- IDE 工作台内部按服务、注册表和贡献重构，为后续扩展打基础。
- 终端登录 shell 不再用缓存的环境初始化。
- 编辑器读取一段的行时不再复制整段内容。

修复
- Windows 关机时不再崩溃；托盘里的「退出」再次选择也能退出，退出过程不再崩溃。
- macOS 文本框粘贴不再等待复制内容的应用。
- 数字键盘开启 NumLock 时，1 和 7 能正常输入。
- Markdown 预览的滚动条上是箭头指针，不再是输入光标。
- 后台有任务时，队列消息的「Send now」也能用。
- 同名模型来自不同上游时可以区分，子代理的模型显示为它自己的上游。
- 打开用量页面时能看到正在读取的调用。
- 主题设置保存失败时保留原来的偏好。
- 表格里的文字像周围文字一样选择。
- 可以列出包含某个提交的分支。
- Windows 上工具调用显示短文件名。
- 终端保留 shell 的选择。
- 已删除的 SSH 主机在启动时不再连接。
- 一个账号刷新额度时，所有账号一起刷新。
- 问题选项悬停时立即高亮。
- 侧边栏折叠的分组会在有 agent 工作时转动，工作和等待中的 agent 不会被「显示更多」挡住。
- 对话窗口只剩一个窗格时，⌘W 等关闭窗格的快捷键能关闭窗口，以前没有反应。
- 已关闭窗口的通知不再弹出。
- 编辑消息时，行内编辑器打开和变高都会滚动到可见，不会被挡住。
