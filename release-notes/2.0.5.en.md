This release brings web search to models without native web search, lets the phone relay setting list several relays as fallbacks, and keeps a new chat's draft when you switch its project.

New
- Upstreams without native web search (such as OpenAI Chat-compatible ones) can now search the web: BaoCode asks several search engines at once and merges their results.
- Settings → Mobile: list several relays in order (BaoCode's or custom addresses); when the current one is out of reach for 5 seconds the next is used, and the earlier one is taken back once it answers.

Improved
- Web search steps reliably show the result sites' icons, and dark icons stand on a light plate so they stay visible on dark themes.
- Claude Code's ToolSearch steps show the MCP icon.
- The conversation sidebar's list fades out at its scroll edges instead of being cut off.
- Usage pages stay responsive with many subagents at work.

Phone (phone app 0.2.5)
- A sent message can be sent again unchanged.
- The question, approval or plan card the agent is waiting on folds down to its heading with a tap.
- Fixed conversation cards from bots showing "No longer listed".

Fixed
- A new chat's draft (text and images) is kept when you switch its project after typing.
- Custom subagent models work across upstreams, and only send an effort level the model offers. Thanks to @zmaker127.
- Windows: /c/x paths written by agents working in Git Bash now open as drive C:.
