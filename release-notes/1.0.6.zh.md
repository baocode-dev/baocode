新功能
- 新增 ChatGPT（Codex）上游：在设置 → 模型中添加，用 ChatGPT 账号登录后，按订阅套餐的额度使用 Codex 模型，无需 API Key。
- 一个 ChatGPT 上游可以添加多个账号，支持三种负载模式：轮询、用完再换、剩余优先。某个账号额度用尽时，请求会自动换到下一个账号。
- 设置中可查看每个账号的套餐、已用额度和重置时间。
- MCP 服务器请求填写信息时会弹出卡片：表单逐项填写，需要打开的链接（如授权页）确认后在浏览器中打开。

改进
- 完全访问模式下，代理提出的问题和待审批的计划仍会弹出等你决定，其他权限请求照常自动放行。
- 登录 ChatGPT 所需的 1455 端口被其他程序占用时，照常在浏览器中登录，再把登录后的地址粘贴回设置即可完成。
