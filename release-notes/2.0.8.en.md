This release greets new users with a demo conversation, lets you drag upstreams and their models into your own order, makes deleting undoable, and lifts the size cap on files to and from the phone.

New
- On first launch with no project yet, a ~/BaoCode project is set up and a demo conversation plays in it: web search, subagents, edits, tests and a picture made, none of it really run. Show the Demo Conversation in Ctrl+P plays it again.
- Settings → Models: drag upstreams, and the models in each, into your own order; the model picker and every model menu follow it.
- Deleting agents, removing a project from the list and deleting a workspace no longer ask first: they are hidden at once, with Undo at the bottom left for 5 seconds.
- Files to and from the phone go in pieces, with no 8 MB cap.
- The built-in core honors CLAUDE_AUTOCOMPACT_PCT_OVERRIDE to compact earlier.

Improved
- File edits show folded to one line by default, opening to the diff; Settings → Appearance switches back to the card.
- The conversation is 1040 wide by default; 720 is still the narrowest.
- More than three background tasks are no longer folded by default.
- With no model set up, the model welcome no longer pops up by itself: the banner and button below the conversation open it.
- Pictures made in past conversations still show with the image model turned off.
- In a multi-folder workspace, the commit panel lists only the repository picked in the Git log.

Fixed
- Antigravity: session info updates no longer overwrite an existing title.
