Update didn’t install?
- If after Restart to Update the app closed and opened again on the old version (1.0.0 and the first 1.0.1 build may do this), please download 1.0.2 from https://baocode.dev/download and install it over your current version; your settings and conversations are kept.

New
- Settings → Appearance: choose the code font, its size and ligatures, and the interface text size, with a preview as you go; the terminal uses the font and size too
- A very long text pasted into the input goes in as a tag (such as “Pasted text #1 +120 lines”) instead of freezing the window; hover it to preview, and the whole text is sent with the message

New in 1.0.1
- A side panel beside the chat: browse the project’s files, review, stage and commit Git changes (with a commit message Claude can draft), and open terminals and the commands an agent runs in the background
- See the files Claude changed in the side panel, and edit and save them there
- Workspaces: put several folders together and let an agent work across them all; Git repositories nested in them are found too
- Refer to other conversations with @ in the input, and copy a session’s ID from an agent’s menu in the sidebar
- SSH remote projects on macOS hosts
- Mermaid diagrams in chat and Markdown files drawn as diagrams, offline, and zoomable
- The agent’s plan shown as a card, and a setting for the width of the chat
- Copy, cut and paste files in the explorer
- A background command’s output in the side panel is shown in a real terminal, with the terminal’s font, colors, selection, find and links

Improved in 1.0.1
- Claude Code’s first-run onboarding is skipped for you, and you’re told when Claude Code can’t be found
- A file opened again is colored at once, without waiting to be highlighted anew
- In a narrow window, the sidebar and the side panel give way to whichever was opened last
- Windows: a new install is for the current user by default, so neither installing nor updating needs administrator rights; installing for all users is still a choice
- More reliable updates: on Windows, the administrator prompt an update asks for comes up in front; an update that didn’t install is told at the next launch, with the download page and the install log
- A version you skipped still shows the Update button in the sidebar; it just isn’t offered in a notification
- Errors, the Windows window log and hang reports are kept in the data folder’s logs folder, to find out what went wrong
- The interaction panel shows the shortcut to go back

Fixed in 1.0.1
- With themes such as Dark 2026 and Dark Modern, the program, strings and options of a command in the chat were invisible
- With light themes, commands and their output in the chat were too faint; they now keep the terminal’s contrast
- A project icon in cyan or magenta showed no color with some themes
- Moving the data directory names the files another program holds open, instead of only reporting that copying failed
- A suggested prompt with a backslash (a Windows path) or a line break turned the input into a grey error box
- Windows: after a display slept, or a window was resized while hidden, the window’s content froze
- Windows: a maximized window on a second screen, restored from minimized, didn’t fill the screen or take input
- The side panel’s rail showed while Customize was open
- Windows: About showed the wrong version, and not the app’s icon
