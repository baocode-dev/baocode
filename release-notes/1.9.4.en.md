This release fixes a crash on Windows when other apps read the window, lets New Terminal pick a folder in a multi-folder workspace, and fixes a few smaller problems.

New
- In a multi-folder workspace, New Terminal (under the conversation, in the side panel and in the IDE) asks which folder it starts in, and the terminal's tab shows that folder.

Fixed
- Windows: the app no longer crashes when another app reads what is on the screen (input methods, translators, screen tools), as could happen when clicking repeatedly in a maximized window.
- Claude limit resets: the one that can be used now is marked and used; the others wait their turn, and a refusal is explained in plain words.
- Deleted lines in diffs line up their tabs with the editor's.
- The phone app keeps showing a conversation's context usage after the conversation changes.
- Windows: file links an agent writes as /D:/path open, rather than saying the file cannot be found.
- Bots from before their messages became tags speak in the chat again, rather than to tools that are gone.
