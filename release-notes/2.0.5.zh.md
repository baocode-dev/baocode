这一版让不支持原生网页搜索的模型也能联网搜索，手机中继支持按顺序配置多个备用，并修复了切换新对话项目时草稿丢失等问题。

新功能
- 不支持原生网页搜索的上游（OpenAI Chat 兼容等）现在也能用网页搜索：BaoCode 同时查询多个搜索引擎并合并结果。
- 设置 → 手机：中继可以按顺序列出多个（BaoCode 自带或自定义地址），当前中继 5 秒连不上就自动换下一个，恢复后再切回。

改进
- 网页搜索步骤稳定显示结果网站的图标，深色图标会垫上浅色底，不再在暗色界面里看不见。
- Claude Code 的 ToolSearch 步骤显示 MCP 图标。
- 对话侧边栏列表滚动到边缘时渐隐，不再被硬切。
- 子智能体很多时，用量页面不再越来越卡。

手机（手机版 0.2.5）
- 已发送的消息可以原样再发一次。
- 智能体等你回答的提问、审批或计划卡片可以点标题折叠。
- 修复机器人发来的对话卡片误显示「已不在列表中」的问题。

修复
- 新对话先输入内容再切换项目时，草稿（文字和图片）不再丢失。
- 自定义子智能体模型可跨上游使用，并只发送该模型支持的推理强度。感谢 @zmaker127。
- Windows：智能体在 Git Bash 里写出的 /c/x 形式路径，现在能正确识别为 C: 盘并打开。
