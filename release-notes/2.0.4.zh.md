这一版新增 Antigravity 账号支持（登录 Google 账号即可对话、网页搜索与生图）、从任意一轮分叉对话、内置内核提示词设置，并大幅提升了大项目全局搜索速度。

新功能
- 支持 Antigravity 账号提供方：通过 Google OAuth 登录即可查看各模型独立配额，额度用完时按模型自动切换账号，并支持原生网页搜索与图像生成。
- 从任意已完成的一轮分叉对话：点击回复底部的分叉按钮，即可从该轮开启新对话继续探索。
- 新增「内置内核」设置页：可按需保持默认系统提示词、追加自定义说明，或替换默认核心说明。
- 网页搜索与网页读取步骤展示来源网站图标，MCP 步骤有了专属图标。
- 对话小地图支持切换左侧或右侧显示（设置 → 外观 → 小地图位置），并与侧边栏导轨对齐。
- 独立运行的技能（如 /code-review）会以子智能体卡片实时展示进度，不再显得像卡住一样。

改进
- 对话中途跨上游切换模型直接生效，不再弹出确认框。
- 每轮回复底部的费用根据「用量价格」和记录实时计算，改价后立即刷新；未定价的调用不再误显 $0.00。
- 单独按 Esc 不再中断正在进行的回复（可按 Ctrl+Esc / Cmd+Esc / Alt+Backspace 或点停止按钮中断）。
- 全局文件搜索改为多核并行扫描，大项目搜索大幅提速，结果与 VS Code 保持一致。
- 减少侧边栏项目重复排序，macOS 关闭无障碍语义树，降低界面卡顿。

手机（手机版 0.2.4）
- 跨上游切换模型不再弹出确认框。
- Antigravity 上游显示 Google 图标，配额池名称排版更清晰。

修复
- 对话文本选区与复制：拖动选择时不再随滚动跑偏或被内层滚动条打断，复制出的文本与屏幕所见一致。
- 修复模型选择器搜索框使用输入法组合和回车提交的问题。感谢 @DedSecer。
- 修复界面缩放时排队消息拖动错位的问题。感谢 @clddup。
- 修复远程工作区撤销（Rollback）误操作本机废纸篓的问题。感谢 @Sxuan-Coder。
- Windows：修复安装程序启动后无法访问目录联接、多窗口下 Fast IDE 在后台窗口打开，以及窗口缩放边框判断不准的问题。
- 修复系统钥匙串不可用或 PowerShell 受限时密钥无法保存，以及 macOS 钥匙串命令未指定默认钥匙串的问题。
- 修复远程主机失联较久仍显示「连接中」、完全访问模式下在 Plan 中仍弹确认，以及已开始的计划再次向用户确认的问题。
