这一版主要是 Bot 管智能体的能力补齐了：开对话、派活、等结果、看改了哪些文件，都和对话里的 agent 一样。另外快速打开在大项目里能找到全部文件，Linux 远程主机上大目录不再卡住连接。

新功能
- Bot 管智能体用上和对话一样的工具：开新对话可以选模型、开一个新分支的 worktree；对方在忙时消息会排队，不再被拒；能读完整回复、等它做完、查看它改了哪些文件。
- 对话被提前自动压缩时会说明原因：上游嫌请求太长，模型实际能接受的比设置的上下文小。压缩分隔线也有了中文。
- Java：多模块工程共用一个语言服务器；工程导入失败时会弹出提示，能直接查看日志，不再只显示「未找到引用」。感谢 @bestK。

修复
- Bot 派出去的对话，电脑端重启后它还认得，做完照样通知它。
- 电脑端重启后，手机不再把 Bot 之前发过的消息再推送一遍。
- Bot 没开「接收智能体通知」时，派活会告诉你它收不到完成通知。
- 快速打开（⌘P / Ctrl+P）在超大项目里能找到所有文件，不再只列前 5 万个。
- Linux 远程主机：监听几万个文件夹时，批量重命名或重连不再让连接卡住几十秒。
- 诊断：Mac 上用输入法时窗口突然点不动的情况会记进日志，方便排查。
