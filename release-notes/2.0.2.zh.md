这一版主要是修复：Windows 上滚轮突然不能滚、工作区窗口标题显示成一串 ID 等问题都修好了。ChatGPT 订阅出了新模型，不用等 BaoCode 发版也能马上选到。

新功能
- ChatGPT 订阅的新模型不用等 BaoCode 更新：模型列表会先从官网取最新的 Codex 版本号，新模型出来就能在列表里看到，不用重启。设置里每个上游的「Codex 版本」一项随之去掉。

手机（手机版 0.2.2）
- iPhone 可以用 curl 推送：设置 → 通知 →「用 curl 推送」开启后，脚本、快捷指令、CI 都能给手机发通知，点开还能打开链接或运行快捷指令。说明见 baocode.dev/zh/push。

修复
- Windows：显示器切换或睡眠唤醒后，鼠标滚轮不再整个失灵，要调整窗口大小才恢复。
- 工作区的窗口标题、窗口菜单和「切换窗口」显示工作区的名字，不再是一串 ID；改名后跟着变。
- agent 在临时目录（/tmp 等）里自己开的对话不再塞满侧边栏，你从 App 里打开或发过消息的才显示。
- 自动内核又没配上游模型时，连 SSH 主机不再自动给主机装 Claude Code，而是提示你选一个模型。
- 有的模型把几条推荐回复写在一起，现在会正确拆成几条，不再变成一整条。
- 诊断：输入框里有键按了没反应时会记进日志，方便排查「某个键突然打不出字」。
