This release draws the app's own header on Linux, lets Antigravity ask you questions and no longer takes its long commands for a hang, and folds a `<details>` written on one line.

New
- Linux: the top of the window is the app's own header, as on Windows; drag its empty part to move the window, and a double click maximizes or minimizes as the system is set.
- Antigravity: its questions come to you as question cards, its subagents' too.
- Antigravity: its checklist of steps shows as tasks, and a message sent mid-turn goes to it at once instead of waiting for the turn to end.

Improved
- Antigravity: calls to BaoCode's own MCP tools (browser, sessions…) show what they returned instead of "(no output)", and MCP tools it calls through `call_mcp_tool` are shown and approved as MCP tools, not as Bash commands.
- A `<details><summary>…</summary>` written on one line folds, as does one written whole on one line, its `</details>` too; a long reply is no longer cut inside one.

Fixed
- Antigravity: commands and MCP calls that run long are no longer taken for a hang and restarted; if it doesn't honor Stop within 15 seconds, its process is ended, so Stop still works.
