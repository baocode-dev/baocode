这一版让对话里选中的文字可以直接复制、引用或顺便问一句，网格布局不再限于 2×2，停下或出错的最后一轮可以一键重跑，并修复了 Linux 和 Windows 上的一些问题。

新功能
- 在对话里选中文字后，上方出现工具条：复制、引用（作为标签放进正在写的消息）、顺便问一句。
- 网格布局不再固定 2×2：可以按行或按列任意拆分，窗口放得下多少格就能开多少格。
- 最后一轮被停下或出错时，旁边多了「重新运行这一轮」按钮，可以先换模型再跑；和编辑消息一样，会询问是否撤回这一轮改过的文件。
- 建议回复现在给出两到四条，按住 ⌘ 或 Ctrl 点击可以同时选上几条，一起发送。
- 发送的图片会同时存成文件并告诉智能体路径，让它上传或附加图片时能找到发的那一张。
- 对话的文件页右键菜单新增「在终端中打开」。
- 模型测试失败时，点「失败」即可复制错误信息，菜单里也有「复制错误」。

改进
- 以斜杠命令运行的技能（如 /code-review）在运行过程中就会显示进展，不再整段空白直到结束。
- 退出应用时，排在运行中回合后面的消息会放回输入框保存，下次打开还在。
- 有定时任务或循环在等待的对话，切到别的对话后也不会被回收进程，任务能按时触发。

修复
- 选中文字时工具条每隔一次才出现的问题。
- 界面缩放不是 100% 时，编辑消息的编辑框位置偏移、被输入框挡住；窗口较矮时编辑框跑出视野。
- Windows：托盘图标没能显示时，关闭窗口改为最小化，不再让应用在后台无法找回；能识别 PowerShell 的应用商店别名。
- Windows 上 Ctrl+Y 在 Markdown 编辑器和输入框里可以重做。
- Linux：安装包声明 GL 依赖，修复精简桌面上启动即崩溃；系统证书文件里混有异常内容时不再整体失效；中文等语言环境下代码字体保持等宽。
- 建议回复里带行内代码时不再整组显示成普通文字。
