本次更新以界面优化为主，并支持 VS Code 的主题插件。

新功能
- 支持 VS Code 主题插件：在扩展视图中从 Open VSX 搜索安装，或拖入 .vsix 文件，即可使用其中的颜色主题和文件图标主题。
- 新增内置主题 Bao Dark 和 Bao Light，并设为默认的深色和浅色主题。
- 输入框支持用 @ 引用文件：工作区里的文件和文件夹都能选；输入 /、~/ 或盘符开头的路径时，可以补全本机上的任意文件。
- 模型设置中可以测试模型：在模型菜单中单独测试，或一次测试全部，结果显示耗时或失败原因。
- 侧边栏的对话菜单可以 Fork 对话，复制一份对话记录继续聊。

界面优化
- 消息气泡和输入框的底色、边框统一；输入框获得焦点时显示投影，不再改变边框颜色。
- 多个对话并排时，当前对话外围显示一圈半透明边框。
- 设置里的开关随界面字号缩放；标签页顶部的高亮线更柔和；标签栏两端不再有渐隐遮罩。
- 修复部分主题下代码区滚动时阴影发黑的问题。
- 侧边栏的变更页下方显示源代码管理的提交图。

调整
- 移除 Monokai、Abyss、Quiet Light、Dark (Visual Studio)、Dark 2026、Light 2026 六个主题。正在使用它们的用户会自动切换到 Bao Dark 或 Bao Light。
