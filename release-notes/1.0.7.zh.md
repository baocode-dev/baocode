处处一样，处处不一样

本次更新以界面优化为主，并支持 VS Code 的主题插件。

新功能
- 支持 VS Code 主题插件：在扩展视图中搜索 Open VSX，或拖入 .vsix 文件，即可安装其中的颜色主题和文件图标主题。扩展页面显示 README、功能、更新日志和兼容性，可以检查更新、切换预发布版本、启用或禁用。插件中的代码不会运行，只使用其中的主题。
- 扩展视图分为“主题”和“语言服务器”两个页签，首页列出热门主题。
- 新增文件图标主题选择（命令面板中的 Preferences: File Icon Theme），按上下键即可预览；JetBrains 风格的图标会按深浅色主题显示对应的画法。
- 新增内置主题 Bao Dark 和 Bao Light，并设为默认的深色和浅色主题。
- 输入框支持用 @ 引用文件：工作区里的文件和文件夹都能选，多文件夹工作区的每个文件夹都包括在内；输入 /、~/ 或盘符开头的路径时，可以补全本机（远程项目则是远程主机）上的任意文件。
- 设置 → 外观新增“用户消息样式”：靠右显示为气泡（默认），或整宽显示、滚动时当前这轮的消息停在顶部。
- 设置 → 外观新增“终端字号”：默认跟随界面文字大小，也可以单独设定。
- 设置 → 模型中可以测试模型：在模型菜单中单独测试，或一次测试全部（每次三个）。测试通过 Claude Code 本身发起，与实际对话走同一条路径；结果显示耗时，失败时悬停可查看回复或错误。
- ChatGPT（Codex）上游可以设置 Codex 版本：后端只列出该版本支持的模型，缺少新模型时填写更新的版本号，再刷新模型列表即可。
- 侧边栏的对话菜单可以 Fork 对话，复制一份对话记录继续聊（远程项目同样支持）。
- 能“在访达中显示”文件的地方都可以“另存为”一份副本；远程项目的文件会下载到本机。
- 侧边栏“已归档”菜单新增“全部取消归档”和“删除全部已归档”。
- 多文件夹工作区中，智能体在各个文件夹里的改动都会出现在变更审查中。

界面优化
- 对话的空白页显示 BaoCode 标志。
- 消息气泡和输入框的底色、边框统一；输入框获得焦点时显示投影，不再改变边框颜色。
- 多个对话并排时，当前对话外围显示一圈半透明边框，与窗口边缘留有间距。
- 对话滚动时，上下边缘内容渐隐。
- 设置里的开关随界面字号缩放；标签页顶部的高亮线更柔和；标签栏两端不再有渐隐遮罩。
- 侧边栏的变更页下方显示源代码管理的提交图，与变更一样可以折叠、调整高度。
- 智能体侧边面板中的终端使用编辑器的背景色，与周围一致。
- 侧边栏各分区之间的分隔线贯通左右两端。
- 已是最新版本时，设置 → 更新中显示当前版本的更新说明。

修复
- 压缩上下文后，上下文用量圆环会及时更新（Claude Code 和 Codex）。
- SSH 远程项目中，跳转到定义能打开正确的文件（此前在 Windows 上可能缺少路径开头的 /）。
- 项目内嵌套的 Git 仓库，其中的改动也会出现在变更审查中。
- Windows 上用输入法输入时，输入框里已插入的标签和图片不再被替换成文字。
- 从计划预览下方的回复开始拖选时，不再选中预览里隐藏的计划文本。
- 请求上游时带上 Claude Code 的 User-Agent，避免 agentrouter.org 等中转返回 401 “unauthorized client detected”。
- README 和 Markdown 预览中 shields.io 徽章的文字不再显示得过大。
- 修复部分主题下代码区滚动时阴影发黑的问题。

调整
- 移除 Monokai、Abyss、Quiet Light、Dark (Visual Studio)、Dark 2026、Light 2026 六个主题。正在使用它们的用户会自动切换到 Bao Dark 或 Bao Light。
