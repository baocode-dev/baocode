# Site icons

The icons of Settings → Network's connection test, as Iconify
(https://icon-sets.iconify.design) serves them: Remix Icon's filled logos,
in one color (`currentColor`), drawn in the text's.

| File | Iconify icon |
| --- | --- |
| google.svg | `ri:google-fill` |
| youtube.svg | `ri:youtube-fill` |
| anthropic.svg | `ri:anthropic-fill` |
| openai.svg | `ri:openai-fill` |
| baidu.svg | `ri:baidu-fill` |
