滑动窗口版的限流写好了：按「上一窗口计数 × 剩余比例 + 当前窗口计数」估算请求数，窗口边界不再出现突刺。计数存储做成了可替换的接口，内置内存和 Workers KV 两种实现。

The sliding-window limiter is in: it estimates requests as “previous window × the share left + this window”, so there is no burst at the window’s edge any more. The counter store is an interface, with a memory one and a Workers KV one built in.

测试结果Tests

  • 新增 9 个用例，覆盖窗口边界、并发请求和存储失效，全部通过（9 new cases, for the window’s edge, concurrent requests and a failing store, all passing (bun test src/middleware/rate-limiter）。).
  • 响应头换成 IETF 草案的 Headers now the IETF draft’s RateLimit 和 and RateLimit-Policy，旧头保留一个版本。; the old ones kept for a release.

迁移说明写在 How to migrate is in MIGRATION.md。.
