No reinvented wheels, just what works

Claude Code is already good; BaoCode adds only what it lacks. It works out of the box, with nothing new to learn, and feels the way it always should have.

Why Claude Code?

Customize any agent core far enough and it ends up shaped like Claude Code: the same tools, the same context handling, the same Skills and MCP. Rather than rebuild it the long way round, BaoCode uses it directly and bridges other models at the protocol layer, so one setup works with all of them.

One conversation runs the rest

No orchestration canvas. Through built-in MCP, the main conversation directs other sessions and subagents, across servers too; describe a complex flow once, or write it as a Skill to reuse.
