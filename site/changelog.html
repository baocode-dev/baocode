Changelog

What changed in each version of BaoCode.

1.0.0

The first release of BaoCode: a desktop app for Claude Code, with a fast IDE built in. For macOS (Apple silicon and Intel) and Windows.

Chat

  • Steps fold into single lines, and the current task and its progress stay above the input
  • Review what Claude changed, file by file, and keep or undo it; checkpoints never touch your repository’s .git
  • Give Claude a goal with /goal, and it keeps working until the goal is met
  • A rich-text input: paste images, drop in files, and copy code from the editor as a reference to its lines
  • Edit a message you sent, search your conversations, and see your context and plan usage
  • Run several agents side by side, in tabs or in windows of their own
  • Choose how the commits and pull requests Claude writes are credited

SSH remote projects

  • Open a folder on a Linux host over SSH, as with VS Code’s Remote-SSH: the window stays on your machine, and files, search, Git, terminals, language servers and Claude Code run on the host
  • Pick a host from ~/.ssh/config, or type user@host
  • Claude Code is installed on a host that has none, and your models work there too
  • Reconnects by itself; when a host can’t be reached, you’re told why and can retry

Fast IDE

  • An editor, a terminal and Source Control with a commit graph and Git blame
  • Your VS Code themes, keybindings and language servers
  • Markdown files open as a preview you can edit in place, Typora’s way
  • Commit messages drafted by Claude Code, for you to edit and commit

Models and extensions

  • Use other models through Claude Code: Anthropic’s API, OpenAI’s Chat Completions or Responses, with API keys kept in the system keychain
  • Choose the model for each part of Claude Code’s work, and for titles and commit messages
  • Plugins, MCP servers, skills, subagents, rules, commands and hooks in one place, with your skills from claude.ai

Around the app

  • Notifications, a sound and a count on the app’s icon when an agent needs you; agents keep running in the menu bar or tray when the window is closed
  • Open a folder in BaoCode from Finder or Explorer, and keep a window on top of others
  • In English and Chinese
  • Updates itself in the background, and asks before restarting
