让 BaoCode 的 agent 使用你自己的浏览器，带着你的登录状态：打开网页、阅读、点击和输入，你可以在侧边栏里实时看着它操作。它只能看到你共享给它的标签页，也就是黄色的「BaoCode」标签页分组，其他标签页仍然只属于你。所有数据都留在你的电脑上。macOS 和 Windows 都支持。隐私说明。

用开发者模式加载 zip：解压到一个会一直保留的文件夹（浏览器每次都从这里加载），打开 chrome://extensions，打开右上角的「开发者模式」，点「加载已解压的扩展程序」，选中这个文件夹。更新时把新版解压覆盖旧文件夹，再点扩展卡片上的刷新按钮。

装好后，在 BaoCode 里打开 设置 → 浏览器，确认已经连上。

开始之前

装了 Claude Code 的话，BaoCode 会直接运行它，沿用你的设置和登录。没装的话，BaoCode 用你添加的模型服务商运行，第一次打开时会一步步带你设置。然后打开一个文件夹，开始对话。

不确定你的 Mac 是哪种？在苹果菜单里选择“关于本机”：显示“芯片”的是 Apple 芯片，显示“处理器”的是 Intel。

在 Mac 上，把 BaoCode 拖进“应用程序”文件夹。它还没有经过 Apple 公证，所以第一次打开时会被 macOS 拦下：打开“系统设置”→“隐私与安全性”，点 BaoCode 旁边的“仍要打开”。只有第一次需要这样做。

在 Linux 上，用系统的软件安装器打开 .deb，或者在下载目录里运行 sudo apt install ./BaoCode-*.deb。装好后应用列表里就有 BaoCode，终端里输入 baocode 也能打开。不确定是哪种处理器？运行 uname -m：x86_64 是 x64，aarch64 是 arm64。

更新

BaoCode 会在后台自动更新，重启前会先询问；在 Linux 上安装时会要你输入密码。如果是它把你带到这里，说明它没法自己更新：从上面下载新版本，直接覆盖安装旧版本即可。你的设置和对话都会保留。
