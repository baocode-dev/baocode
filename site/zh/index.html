为什么做它

我们每天都在用 Claude Code。终端适合运行它，却不适合阅读它：长长的 diff 一下就滚出视野，之前的步骤很难再找回来，想审查它改了什么还得切到别的应用。

BaoCode 就是我们想给它配的那个窗口。原生绘制，打开即用，界面从不拖 Claude 的后腿。

后来它越长越大：agent 能用你自己的浏览器，能生成和看图片，能跑在任何模型上；想法可以随手记进 Stash，等准备好了交给它；人不在电脑前，也能在手机上接着管。这些都在同一个原生应用里，依旧轻快。

界面

界面是 BaoCode 的重点，所以大部分功夫都花在细节上。这些细节平时你未必注意得到，直到换回别的工具：

  • 步骤自动折叠。读文件、搜索和命令都收成一行，对话读起来就是 Claude 说了什么、做了什么。
  • 每处修改都能审查。Claude 改过的代码直接标在编辑器里，每一段都能单独保留或撤销，也可以按文件、一次性全部处理；在对话旁边的侧边栏里就能看，不用切去 IDE。检查点只保存 agent 改过的文件，存放在 BaoCode 自己的数据目录里，从不放进你仓库的 .git。
  • 看得见它在做什么。Claude 工作时，当前任务、正在运行的子代理和后台任务一直显示在输入框上方；已用时间、输出速度和 token 数实时滚动，每轮结束后还有耗时和花费。
  • 长对话一眼看全。对话旁边有一张整段对话的缩略图，你的消息、代码、表格和改动都分辨得出来；一块液态玻璃标出你看到哪里，点一下或拖一下就跳过去。再长的对话也从最后读起，往上翻时才加载更早的部分，打开不用等。
  • 给它一个目标。输入 /goal 和你想完成的事，Claude 会一直工作到目标达成。目标显示在输入框上方，附带已经工作了多久；展开可以看到它为什么还没达成，也可以修改目标。任务进行到一半时设定，也会立即生效。
  • 输入框是富文本编辑器。从编辑器复制代码，粘贴过来就是对文件和行号的引用；粘贴图片或拖入文件，它们就留在你放进句子的那个位置。用 @ 引用文件，一键「润色」把话理顺，标签和代码原样保留。Claude 还在忙时发出的消息会排在输入框上方，依次发送，也能撤回或插队。

你的 Chrome，agent 的 DevTools新推出

agent 用的就是你每天在用的那个 Chrome（Edge、Brave、Arc 也行），带着你的登录状态、Cookie 和扩展，不是另起一个什么都没登录的无头浏览器。装上 BaoCode 扩展，它拿到的也不只是「打开网页、点一点」，而是 Chrome 开发者工具里的每一个面板：28 个浏览器工具，查后台、测你刚写的页面、追一个只在线上出现的 bug，都在你的浏览器里做完。

它只能碰你共享给它的标签页，也就是浏览器里黄色的「BaoCode」分组：工具栏上的 BaoCode 按钮把当前标签页交给它，拖出分组就收回来。BaoCode 的侧边栏实时显示它在用的页面，你随时可以在里面点、在里面打字，直接接手。扩展只负责传话，所有数据都留在你的电脑上。

扩展可以从 Chrome 应用商店安装，也可以下载 zip 手动加载；macOS 和 Windows 都支持。它做了什么、不做什么，见隐私说明。

Stash

好点子总在你忙别的事时冒出来。给 Stash 设一个全局快捷键，在任何应用里按下就弹出一个小面板：文字、截图、文件、链接、代码都能扔进去，每条都有自己的编号，像 issue 一样。

准备好了，点「在 BaoCode 中实施」，选在新的 git worktree 里做还是直接在当前分支上做；也可以在对话里 @ 它。对话和便签自动关联，卡片上实时显示进展。觉得写得太潦草，「说清楚」会结合图片和附件把一句话补成完整的需求。

登录 GitHub 或 GitLab（也支持 GitHub Enterprise 和自建 GitLab），还能把 issue 导进 Stash，链接的 issue 和 PR 显示最新状态和检查结果；回帖、关闭 issue 都要你点头，发出前还会提醒内容里是否带了本机路径或密钥。

图片

让 agent 画个图标、做张配图、出一版界面草图，它会用你上游里的图片模型直接生成，存到你说的位置：Images API、OpenRouter 和 Gemini 这类对话接口、Codex 的 gpt-image-2 都能用。

图片也直接显示在对话里：它读的图片文件、浏览器截图、MCP 工具返回的图，还有消息里的本地图片。点开看大图，用 ← → 翻遍整个对话的图片。网上的图片仍然只显示为链接，免得一加载就把它读过什么告诉了别人的服务器。

速度

VS Code 和 Cursor 基于 Electron。每个窗口都是一个网页，每份应用都自带一个 Chromium 浏览器和 Node.js。启动要好几秒、内存动辄上 GB、安装包 200 MB，原因都在这里。

BaoCode 不是网页。它是原生应用，直接用 GPU 绘制自己的界面，底下没有浏览器。

你的主题

BaoCode 的配色就是 VS Code 的主题配色，你常用的主题看起来和你预期的一样：编辑器、对话和侧栏都跟着主题走。随时可以换主题；在列表里上下移动时，窗口会逐个预览。

不止自带的那些：在扩展视图里搜索 Open VSX，或者拖进一个 .vsix，就能装上 VS Code 的颜色主题和文件图标主题。我们自己也做了一套 Bao Dark 和 Bao Light，作为默认主题。

BaoCode 对整个 VS Code 也是这么做的：留下最重要的部分，装进 Windows 上 16 MB 的安装包里。

Fast IDE

想自己看代码时，不用再开别的应用。Fast IDE 是内置的：编辑器、终端，以及带提交图的源代码管理，沿用你的 VS Code 快捷键和语言服务器。点一下就回到对话。

它的响应以毫秒计。即使在大项目里，打开文件、出搜索结果、按键上屏，都快到你感觉不到等待。

提交信息由 Claude Code 来写：它读你的改动，起草好提交信息，你修改后提交即可。它怎么写也可以自定义。获取、拉取、推送都在这里；提交图能显示所有分支，标出每个提交在哪些分支和标签上；多仓库的项目和子模块各自独立。

想盯着 agent 写代码，就打开「以 Diff 显示智能体改动」：它每改一个文件，就以 Diff 打开，随改随看。

SSH 远程项目

代码不必放在你自己的电脑上。通过 SSH 打开 Linux 服务器上的文件夹，体验和 VS Code 的 Remote-SSH 一样：窗口留在本机，文件、搜索、Git、终端、语言服务器和 Claude Code 都在服务器上运行，就在代码旁边。

从 ~/.ssh/config 里选一台主机，或者直接输入 user@host，再选一个文件夹就行。远程项目和其他项目一起列在侧栏里，标着所在的主机；新对话也可以从输入框上方的文件夹菜单直接在远程项目里开始。服务器上没有 Claude Code 时，BaoCode 会帮你装好，你添加的模型在那边也能用。

连接断了，BaoCode 会自己重连；被打断的对话，发下一条消息时就会接着进行。连不上主机时，它会告诉你原因，点一下就能重试。

服务器需要是 Linux（x64 或 arm64）。SSH 密钥、ssh-agent 和密码登录都可以，密码可以记在系统钥匙串里；登录时要输入的验证码也会在 BaoCode 里问你。

手机

出门了，agent 还在家里的电脑上干活。手机上的 BaoCode 和电脑配对后，就能查看电脑上每个智能体在做什么，回答它的问题、授予权限、批准它的计划，或者给它发下一条消息。

扫码就能配对，同一个网络里的手机也能直接发现这台电脑。配对时两端核对安全码，之后经局域网或公网直连，内容端到端加密；电脑换了 IP 也不用重新配对，也可以经 Cloudflare Tunnel 连接。Android 测试版可以直接下载 APK，iPhone 和 iPad 的测试版在 TestFlight 上，都在下载页。

技能、MCP 服务器及其他

Claude Code 能用来扩展的一切都集中在一处：插件、MCP 服务器、技能、子代理、规则、命令和钩子，可以对你全局生效，也可以只用于某个项目。你在 claude.ai 上的技能也会出现在这里。

任意模型

活由 Claude Code 来干，模型由你来选。添加一个支持 Anthropic API、OpenAI Chat Completions 或 OpenAI Responses 的上游，BaoCode 的本地代理会在它和 Claude Code 之间做转换。Claude Code 的工具、技能和工作方式都保持不变。你甚至可以让 Claude Code 跑在 GPT-6 Astra 上。

有 ChatGPT 套餐的话，直接用 ChatGPT 账号登录，按套餐额度用 Codex 的模型；登录几个账号，额度用完的会自动让给下一个。在支持的站点上点一下「导入」，上游和你的密钥就加好了。添加完可以一键测试每个模型，也可以给上游加自定义请求头。

API 密钥保存在系统钥匙串里，而不是设置文件中；你还可以为 Claude Code 的每类工作分别指定模型，每个对话也能单独换模型。

通知

你不用一直盯着窗口。当智能体需要你回答问题、授予权限或批准计划，或者它完成了这一轮，BaoCode 会用系统的方式告诉你：一条通知、一声提示音，应用图标上还会显示有几个智能体在等你。

关掉窗口后，智能体仍在菜单栏（Windows 上是托盘）里继续运行，菜单里能看到哪些在等你。默认提示音是微波炉的“叮”，因为活儿热好了：

在“设置 → 通知”里，也可以选择 man-oh-yeah、Gulp Gulp Gulp Gulp、系统音效或自己的音频文件。多个智能体同时通知时，各段提示音重叠播放，不会互相打断。

它不做什么

BaoCode 不另起一套智能体生态，这是有意为之。Claude Code 的生态无可比拟：工具、技能、插件、MCP 服务器、子代理和钩子。再做一套只会把它割裂开。BaoCode 要做的，是给 Claude Code 配上它应得的界面，并让周边的一切开箱即用。

所以 BaoCode 不附带模型，也不需要注册账号。本机装了 Claude Code，它就运行你的那一份，用你的设置、你的登录和你的 CLAUDE.md。没装的话，BaoCode 有自己的内置内核：同样读 CLAUDE.md、技能、子代理、命令、钩子、插件和 MCP 服务器，跑在你在 设置 → 模型 里添加的上游上。想用 Claude 订阅，就在 设置 → 通用 → 内核 里选 Claude Code CLI，没装的话 BaoCode 会帮你下载。

不支持 Codex CLI 等其他智能体；它们的模型可以像上面说的那样，通过 BaoCode 使用。
