BaoCode 每个版本的变化。

1.7.3

修复 1.7.2 的 Bot 在没用手机时也在后台运行的问题。

修复

  • 没有配对手机时，Bot 不再收到 agent 的动态，也不会按约定回来找你。以前每条动态都会让 Bot 用你的模型回一轮，花了钱却没人看到。配对手机后再照常进行。
  • Bot 的对话不再出现在桌面的系统通知、Dock 角标和托盘里，点通知也不会把它当成普通对话打开。
  • 每个 Bot 多了一个「接收智能体通知」开关，默认关闭，助手也一样。打开后它会收到所有 agent 的等待、出错、完成和久跑；关着时只会收到它自己开的或发过消息的 agent。手机上需要 0.1.4。
  • 收到 agent 的动态时，和当前聊天无关的 Bot 会直接略过，不再每条都回一句。

1.7.2

这一版的重点是手机上的 Bot：像人一样和你聊天的智能体，跑在你的电脑上，在手机上和它们对话。另外，分屏可以各自带侧边栏、拖动换位置，还修了一些问题。

Bot（在手机上用，需要这一版桌面端）

  • 每个 Bot 有自己的名字、头像、性别、签名、说话风格和模型。默认有一个助手，也可以自己新建。
  • Bot 能做什么由你逐项打开：照看你的 agent（查看、停止、重试、归档、发消息、开新的）、使用你的浏览器、在 agent 等你或出错时主动告诉你。
  • Bot 可以上网，会记住你说过的事；在 设置 → 模型 里打开图片模型后还能生成图片。你发给它的图片它也能用，比如拿来当头像。
  • Bot 不读写电脑上的项目文件，项目里的活交给 agent。

新功能

  • 分屏时每个对话有自己的侧边栏，单独显示或隐藏。
  • 拖动分屏的标题栏，可以把它放到另一个旁边，或者两个互换位置。把项目的「新建 agent」拖到分屏上，会在旁边开一个新的。
  • 侧边栏里的文件可以用默认应用打开，菜单里还有在终端、文件管理器里打开和复制路径。
  • IDE 左侧活动栏底部加了设置按钮。
  • 手机上能看到 agent 生成的图片、工具返回的图片、浏览器的每一步操作，以及目标和本轮用量。
  • 内置核心和 Claude Code CLI 2.1.293 对齐。

修复

  • 进程还在启动时点「立即发送」，会等它准备好再发。
  • 读取上游 key 失败不会被记住，也不会冲掉期间新设的 key。
  • 浏览器发来的长消息收全了才处理。
  • 用量以字符串返回的模型，用量能正确显示。
  • 从输入框复制时保留标签，粘贴到别的应用是纯文本。
  • Markdown 文件的改动默认显示渲染效果，点一下看 diff；侧边栏的文件树带 Git 状态。
  • Git 日志的图完整显示，详情可以复制，分支也显示出来。
  • 提交面板的勾选框看得清，改动可以按列表或树显示，窗口窄时按钮不再挤出去。
  • Windows：分屏标题栏的按钮作用于各自的 agent，和 macOS 一样；改用 Skia 绘制，画面更快、更省内存。

1.7.1

这一版主要帮我们查清「执行过程中卡住、无响应」这类问题：macOS 上界面卡住时会自动记下卡在哪里，上传诊断时一起带上。另外修了聊天终端和分屏的几个问题。

诊断

  • macOS 上界面超过 4 秒没有响应时，会自动记录当时各线程在做什么、卡了多久，写进日志；上传诊断时一起发送。平时几乎没有开销，只有真卡住时才采样，每次运行最多 3 次。
  • 日志会记下每次是怎么退出的（正常退出、更新、被系统结束、崩溃）；上一次异常结束的，下次启动时会注明。
  • 上传诊断时附带系统记录的报告：macOS 的崩溃、卡死后被强制退出、CPU 长时间占用过高，以及 Windows 的错误报告。文件名里的电脑名会去掉。

修复

  • 聊天里的终端按对话分开：每个分屏显示自己项目的终端，宽度和对话一致。分屏标题栏上的终端、侧边栏、编辑器按钮作用于这个分屏自己的智能体。
  • 拖动分隔线调整终端大小时，只在停下后告诉终端一次，不再刷出一屏重复的提示符。
  • 打开远程项目或远程文件时，文件夹读得慢会显示「正在读取…」，选择框不再消失。
  • 源代码管理：「生成提交信息」挪到提交按钮旁边；拖动提交信息上方的分隔线时，分隔线跟着鼠标走，双击恢复默认高度。

1.7.0

新 Git 视图

这一版的主角是全新的 Git 视图：原来的「变更」面板换成了 JetBrains 风格的 Git 日志和提交面板，提交、分支、变基、冲突、暂存、对比这些日常操作都能在 BaoCode 里完成，还可以随时请 AI 帮忙。另外，Windows 现在有 Arm64 原生版；WSL 里的项目可以直接打开；macOS 上的 CPU 占用明显降低了。

新 Git 视图

  • Git 日志：提交图、分支和标签标记都和 JetBrains IDE 一样。可以按分支、路径、作者、日期筛选，多选提交，查看文件、文件夹或某几行的历史。旁边是分支树，分支的常用操作都在那里。
  • 提交面板：勾选哪些文件就提交哪些，不用先暂存；每处改动旁边也有勾选框，一个文件可以只提交其中几行。智能体每一轮改的东西自动归成一个变更列表，也可以自己建变更列表。
  • 提交选项：修改上一次提交（Amend）、指定作者、Sign-off、是否运行 Git 钩子。Ctrl+M 调出以前写过的提交信息；写提交信息时会检查标题长度和空行。未跟踪的文件可以加入 .gitignore，也可以显示被忽略的文件。提交信息可以只根据勾选的改动来生成。
  • 提交前 AI 审查：打开后，提交前先让 AI 看一遍勾选的改动，有问题会先停下来，等你决定。
  • 问 AI：日志里的提交、提交面板里的改动和冲突都能「问 AI」，请求会先放进聊天输入框，你看过再发。差异里某一处改动旁也有按钮，可以把这处改动连同文件和行号放进输入框。
  • 分支：状态栏的分支弹窗可以新建、切换、合并、变基、比较分支。推送有单独的推送对话框；「更新项目」可以选合并还是变基。
  • 变基与冲突：支持交互式变基，可以让 AI 帮你整理提交（Clean Up with AI），还有 Fixup。进行中的合并、变基、拣选或还原会显示在面板顶部，可以继续、跳过或中止。冲突文件可以一键采用某一方，也可以打开三方合并对话框，或者交给 AI 来合并。
  • 暂存（Stash）：可以暂存和恢复改动，有和 JetBrains 一样的 Stash 标签页。
  • 远程与仓库：可以管理远程仓库，把标签推到远程或在远程删除标签；起始页可以直接克隆仓库。
  • 工作树：IDE 的源代码管理可以切换到其他工作树查看。聊天输入框下的分支菜单可以新建、切换工作树，日志里也会标出 AI 正在哪个工作树里工作。
  • 对比：文件可以和某个分支、某个版本、剪贴板或另一个文件对比；可以对比两个文件夹，也可以按提交比较某个分支和当前分支。差异视图可以折叠没改动的部分、忽略所有空白；编辑器的差异标签页里点箭头就能还原那处改动；智能体改过的地方会在差异里标出来。
  • 编辑器：行号旁边用 JetBrains 风格标出改动，可以显示 Git Blame 注解。新增本地历史：保存过的文件会保留一周内的各个版本，打开「显示本地历史」就能和当前文件对比，用箭头把改动拿回来。

Windows Arm64 与 WSL

  • Windows 新增 Arm64 原生版（BaoCode-1.7.0-setup-arm64.exe），在骁龙等 Arm 处理器的电脑上原生运行，之后的自动更新也会下载 Arm64 版。官网下载页已经有 Arm64 按钮。
  • 可以打开 WSL 发行版里的项目：「打开远程项目」会列出本机的 WSL 发行版，文件、Git、终端、语言服务器、Claude Code 和断线重连都在 WSL 里运行，状态栏会显示「WSL: <发行版>」。
  • WSL 里不会再误用 Windows 上装的 Claude Code。以前会报「Settings file not found: E:\dev\shm\…」，现在会提示在 WSL 里安装一份。

性能

  • macOS 上的 CPU 占用明显降低。没有变化的窗口和隐藏的速记面板不再每帧重绘，智能体运行时每帧的绘制时间从 6～11ms 降到 1～2.5ms。
  • 加载动画统一每秒 30 帧，不再各跳各的；IDE 和侧边栏只在显示的内容变化时才重建。
  • Git 和检查点改到后台运行，不再卡界面。没有改动时，一次检查从 13 个 Git 命令减少到 3 个。
  • build、node_modules 这类被忽略的文件夹里有变化，不再触发 Git 状态刷新；模型列表只计算一次。
  • 持续卡顿时会自动采样记录到日志，方便排查问题。原来只有 macOS 有，现在 Windows 和 Linux 也有。

其他新功能

  • 设置 → 外观新增「原生高斯模糊」，控制 macOS 和 Windows 11 窗口底下的系统模糊，默认关闭。
  • 编辑器支持自动换行：设置 → 外观里打开，或者在编辑器里按 Alt+Z 切换。
  • 全屏：在「查看」菜单里选，或者按 F11（macOS 上是 ⌃⌘F）。
  • 缩放界面：⌘= / ⌘- 每按一次把界面大小调 2%（Windows 和 Linux 上是 Ctrl），⌘ + 小键盘 0 恢复。编辑器、侧边栏文件和变更里的代码也跟着等比缩放。
  • 侧边栏：可以把项目置顶，可以一键全部折叠或展开，可以编辑项目的名称和位置（对话会一起跟过去）；鼠标悬停在对话上会显示它用的模型。
  • 编辑器的查找、全局搜索都可以跨行搜索，粘贴多行文字时会保留换行；搜索要包含、排除的文件和各项选项，重启后依然保留。
  • 可以在「打开语言服务器设置」里配置自己的语言服务器，保存后立即生效，不用重启。
  • 后台任务可以清掉已经结束的，单个清或者一次全部清。
  • 内置内核的智能体结束工作时，如果待办事项还没做完，会提醒模型更新一下。
  • 输入框的「润色」按钮改成「提示词增强」：用辅助模型把你写的消息改写成更清楚、更具体的提示词，会参考 AI 上一轮的回复，理解「就按方案二」这类说法。按 ⌘Z 可以撤销。
  • 用 ChatGPT 账号跑 Codex 时，输入框下方显示当前账号的剩余额度，点开能看到每个账号的额度和重置时间。所有账号的额度都用完时，「额度恢复后继续」也支持 ChatGPT 账号了。
  • 智能体知道聊天里能显示数学公式、Mermaid 图表、本地图片和可折叠的段落，会在合适的时候用上；它写的文件链接也更规范，点得开。
  • Mermaid 图表：流式输出时先显示占位图，不再先露出代码；小的流程图用直角连线，竖长的流程图放得下时自动横排；时序图的配色和流程图统一。点开放大、右键菜单都和图片一样，可以复制图片。
  • 任务列表的勾选框改成和链接同色的方框；可折叠段落去掉了左侧竖线。
  • SSH 远程主机上选择文件夹、打开文件时，列表右上角有刷新按钮：在终端里新建的文件夹，不用重新打开就能看到。

修复

  • 对话缩略图要等对话足够长才出现，早期展开、折叠步骤时不会再忽隐忽现。
  • 在 Git 日志里切换文件、在侧边栏切换改动时，不再闪一下。
  • 变基完成后，提交面板不再一直显示「正在变基」，「继续」也不会再报 Cannot continue the rebase。
  • 从列表移除的 WSL / SSH 项目，打开同一主机上的其他项目时不会再冒出来。
  • 子代理改的文件会及时出现在审查里；改了项目外的文件也能看到差异、撤销。通过链接打开的项目，文件不再被当成项目外的。
  • 用其他上游时，Claude Code 设置里的 availableModels 不会再把模型换成 Claude 的。
  • 计划直接发给用户而不是写进文件时，也会显示计划卡片，可以开始执行。
  • 代码块在结束标记处正确结束，不会把后面的回复都当成代码。
  • Linux 上能播放提示音，也会弹出系统通知。
  • 中文 Windows 上，MCP 命令失败时的输出不再是乱码；有些 MCP 服务器检查连接时会被拒绝（HTTP 415），现在不会了。
  • 用输入法在选中的文字上输入时，会正确替换掉选中的内容。
  • Windows 上打开设置时，标题栏只保留窗口按钮。
  • macOS 上从程序坞或访达启动时，同时打开的文件数上限从 256 调高了：以前智能体、终端、语言服务器开多了，会报「Too many open files」，Claude Code 启动不了。
  • 远程主机第一次连不上，重试连上后，文件夹会重新读取。
  • 在对话里拖选文字时，焦点被抢走（比如弹出提问面板）或前面的历史还在加载，选区不再丢失或错位；有时只选中一半的问题也修好了。

  • Windows 上图片预览的关闭按钮不再和窗口按钮叠在一起。
  • 有些主题下，鼠标移到「新对话」按钮上时不再变红；按钮改用侧边栏图标栏的配色，看得更清楚。

1.6.0

性能优化

这一版主要在提速和省内存：长对话里回复流式输出、滚动、拖动缩略图都更跟手，长时间运行占用的内存明显变少，Windows 上画面绘制快了好几倍。另外，Stash 现在能和项目在 GitHub / GitLab 上的 issue 双向同步；SSH 断线后会自动接回原来的会话，远程正在跑的东西一样不丢。

性能

  • Windows 改用 Skia 绘制界面（和 macOS 一样），不再用 Flutter 新默认的 Impeller：实测对话界面每帧的绘制时间只有原来的几分之一，内存也只占原来的一半左右。
  • 长对话流式输出更流畅：回复里的每个文件路径，不再到会话读过的所有文件里逐个去查。在一段 92 轮的真实对话里，每帧耗时从 6.8ms 降到 4.5ms，卡顿帧从 18 个降到 0。
  • 很长的回复和思考过程，离屏幕很远的部分会先释放、只占住高度，滚回来再显示；思考过程只绘制看得见的部分；横向滚动的代码、表格和公式会缓存成图片。全选和复制照样能拿到全部文字。
  • 快速拖动对话缩略图或滚动条时，不再提前构建看不见的内容，松手后再分几帧补上；滚出去又滚回来的回复不用重新解析。来回快速拖动时，每帧耗时从 12.9ms 降到 2.5ms。
  • 更省内存：Skia 留着的纹理缓存从 150～300MB 降到 32MB，图片缓存限制在 48MB；macOS 上释放掉的大块内存会还给系统，长思考流式输出时少占约 180MB。
  • 编辑器更省：同一种语言的文件共用一个语法高亮进程，规则只编译一次（以前 TypeScript 的 334 条规则要在约 3500 个地方各编译一遍）；行排版缓存限制在 32MB 左右。
  • 计划模式下提示词缓存能正常命中了：以前每一轮都要把整个对话重新写进缓存，又慢又费钱。
  • 触控板在编辑器里滑动松手后也有惯性，和列表一致；macOS 上列表滚到头不再回弹。

新功能

  • Stash 与 issue 双向同步：项目是 GitHub / GitLab 仓库时，打开的 issue 会自动成为 Stash，一条一行，状态、标题、关联的对话和 issue 一目了然。两边的修改保持一致：那边改的直接拿过来，这边改的确认后才推上去，两边都改了由你来选；issue 关闭，Stash 也随之完成。默认同步全部打开的 issue，可以在设置 → Stash 的「Issue 同步为 Stash」里改成只同步我的，或者关闭。
  • Stash 动态：issue 有新评论、被关闭或重新打开，关联的 PR 检查失败、被要求修改、已合并，都会在行上标出来，和你有关的计入侧栏 Stash 旁的数字。检查失败或要求修改的 PR 可以一键回到它的对话里去修，已合并的会问你这条 Stash 是否完成。
  • Stash 可以发布成 issue：发布前列出要发出去的内容，并提醒其中的本地路径和密钥，本地图片会一起上传。合并 Stash 时，被合并的那条 issue 可以作为重复关闭。
  • 新的 Markdown 编辑器：Stash、侧边栏里的 Markdown 预览和对话输入框，都改成所见即所得地编辑，标记只在光标所在的地方显示。表格直接在单元格里编辑，能增删行列，像电子表格一样框选、复制、粘贴；链接上会弹出气泡，可以打开、复制、编辑或移除。
  • 自定义：技能、规则、命令和子代理的 .md 文件用 Markdown 编辑器打开，可以直接编辑，也可以切到源码；文件开头的 front matter 显示成属性，像填表一样修改。
  • SSH 断线不丢工作：网络闪断后会自动重连到原来的会话，远程的终端、Claude Code 和语言服务器都继续运行（断开期间最长保留 3 小时），中间的输出不丢也不重复；网络断了 30 秒内就能发现。
  • 达到用量限额后自动继续：用 Claude 自己的账号时，模型选择器里有「限额重置后自动继续」开关。打开后，因限额停下的对话会在重置后自动接着做，电脑睡过了重置时间也一样；应用关着时到点的，下次打开时继续。
  • 推荐使用 Claude Code CLI：本机装了 Claude Code 的，默认就用 CLI；还在用内置内核的对话，输入框上方会建议切换，点一下就自动下载并切过去，不想换就点「暂不」。
  • 模型：子代理和 Opus / Sonnet / Haiku 三档可以选用别的上游的模型；每个模型可以单独指定接口（Anthropic、Chat Completions、Responses）；上游和模型都能一键复制；上游已经下架的模型可以一次移除。
  • 对话缩略图：你发的每条消息在缩略图上都是一个醒目的标记。鼠标靠近会自动吸附，立刻弹出这条消息和前后回复的预览，点一下就跳过去。

1.0.0

BaoCode 的第一个版本：Claude Code 的桌面应用，内置快速的 IDE。支持 macOS（Apple 芯片和 Intel）和 Windows。

对话

  • 执行步骤折叠成一行，当前任务和进度固定显示在输入框上方
  • 按文件查看 Claude 做的修改，逐个保留或撤销；检查点不会碰你仓库的 .git
  • 用 /goal 给 Claude 设定目标，它会一直工作到目标达成
  • 富文本输入框：粘贴图片、拖入文件，从编辑器复制的代码会变成对文件和行号的引用
  • 可以编辑已发送的消息、搜索历史对话，查看上下文和套餐用量
  • 多个智能体并排运行，可以放在标签页里，也可以各开一个窗口
  • 可以设置 Claude 写的提交和 Pull Request 里的署名

SSH 远程项目

  • 通过 SSH 打开 Linux 主机上的文件夹，体验和 VS Code 的 Remote-SSH 一样：窗口留在本机，文件、搜索、Git、终端、语言服务器和 Claude Code 都在远端运行
  • 从 ~/.ssh/config 里选主机，或者直接输入 user@host
  • 远端没有 Claude Code 时会自动安装，本机配置的模型在远端也能用
  • 断线自动重连；连不上时会说明原因，可以一键重试

Fast IDE

  • 编辑器、终端，以及带提交图和 Git 追溯（blame）的源代码管理
  • 沿用你的 VS Code 主题、快捷键和语言服务器
  • Markdown 文件以预览方式打开，可以像 Typora 一样直接在预览里编辑
  • 提交信息由 Claude Code 起草，你修改后提交

模型与扩展

  • 通过 Claude Code 使用其他模型：支持 Anthropic API、OpenAI Chat Completions 和 Responses，API 密钥保存在系统钥匙串里
  • 可以为 Claude Code 的各类工作分别选择模型，标题和提交信息也可以单独选
  • 插件、MCP 服务器、技能、子代理、规则、命令和钩子集中管理，claude.ai 上的技能也会同步过来

其他

  • 智能体需要你时，有系统通知、提示音和应用图标上的数字提醒；关掉窗口后，智能体仍在菜单栏或托盘里继续运行
  • 可以从访达或资源管理器直接用 BaoCode 打开文件夹，窗口也可以置顶
  • 支持中文和英文界面
  • 在后台自动更新，重启前会先询问
